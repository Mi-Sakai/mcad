# mcad — Rust製 2D CAD

Rust + egui で開発している2D CADソフトウェアです。現在 **v0.7.2**。

## 主な機能

- **作図**: 点・線分・円・円弧（始点/通過点/終点の3点指定）・ポリライン・テキスト（CJK 対応）・寸法（長さ/半径）
- **編集**: 選択（クリック/矩形/累積選択）・移動・複製・回転・ミラー・オフセット・**トリム・延長・フィレット・分割**・削除
- **スナップ**: 端点・交点・中点・中心・グリッドを優先度付きで候補選択、種別ごとのマーカー表示
- **レイヤー**: 色変更・表示/非表示・ロック、重ね順(Front / Back ボタンで最前面・最背面へ)、専用パネルで管理
- **undo/redo**: コマンドパターンによる取り消し・やり直し
- **ファイル入出力**: `.mcad`（JSON形式）の保存/読込、DXF のインポート/エクスポート
- **ビューポート**: カーソル中心ズーム、パン、ズームに追従するグリッド表示

## 起動方法

```bash
cargo run -p mcad-app
```

通常利用では `--release` を付けたリリースビルドを推奨します（`cargo run --release -p mcad-app`）。

| キー / 操作 | 機能 |
|---|---|
| `Ctrl+N` | 新規ドキュメント |
| `Ctrl+O` | `.mcad` ファイルを開く |
| `Ctrl+Shift+O` | DXF ファイルをインポート |
| `Ctrl+S` | 保存 |
| `Ctrl+Shift+S` | 名前を付けて保存 |
| `Ctrl+E` | DXF ファイルへエクスポート |
| `Ctrl+Z` / `Ctrl+Y` | undo / redo |
| `Ctrl+D` | 選択集合を複製（基準点→配置先の2クリック配置） |
| `S` | 選択ツール |
| `M` | 選択集合を移動（基準点→配置先の2クリック配置） |
| `R` | 選択集合を回転（pivot→基準点→回転先の3クリック相対角） |
| `Shift+M` | 選択集合をミラー（軸2点指定） |
| `O` | 選択エンティティをオフセット（単一対象、通過点クリックまたは距離入力） |
| `X` | トリム（境界→対象の2クリック、クリック側を除去） |
| `E` | 延長（境界→対象の2クリック、対象を境界まで伸ばす） |
| `F` | フィレット（上部パネルで半径を入力してから、1本目・2本目の線分を「残したい側」で順にクリックすると確定。`Esc` でキャンセル） |
| `B` | 分割（対象をクリック、クリック点で2つに分割） |
| `1` | 点ツール |
| `L` / `C` / `A` / `P` | 線分 / 円 / 円弧 / ポリライン |
| `T` | テキスト（アンカーをクリック後、上部パネルで文字列・高さを入力し `Enter` で確定。`Esc` でキャンセル） |
| `D` | 長さ寸法（計測点 2 クリック → 寸法線位置クリックで確定、3クリック配置。カーソル追従プレビュー） |
| `Shift+D` | 半径寸法（円または円弧クリック → 引出方向クリックで確定、2クリック配置） |
| `Enter` | ポリライン確定（2点以上、開いたまま確定。始点クリックなら閉じて即確定） |
| `Del` / `Backspace` | 選択エンティティを削除 |
| `Esc` | 作図・配置モードのキャンセル / 矩形ドラッグ破棄 / 選択全解除 |
| `F3` | スナップ ON/OFF |
| `F8` | 直交モード ON/OFF（直前の点から水平/垂直に拘束。スナップ候補があるときはスナップが優先される） |
| ホイール | カーソル中心ズーム |
| 中ボタンドラッグ / `Space`+左ドラッグ | パン |
| クリック | 図形クリック: 選択に追加（空クリックは何もしない） |
| `Shift`+クリック | 図形: 選択から個別除外、空クリック: 選択全解除 |

未保存の変更がある状態で新規作成・ファイルを開く・ウィンドウを閉じる操作をすると、破棄してよいか確認するモーダルが表示されます。

## ファイル形式

- **`.mcad` ファイル**: JSON 形式の mcad ネイティブフォーマット。v0.7.2 時点で v3 スキーマ。v1/v2 形式も読み込み可能（後方互換）
- **新規図面**: `"0"` と `"Text"` の 2 つの既定レイヤーで始まります（いずれも削除・改名可能）

## DXF 入出力の注意点

DXF は交換用フォーマットとして扱います。インポート後は必ず `.mcad` 形式で保存し（元の DXF ファイルは上書きしません）、以下の点に注意してください。

- **色**: ACI 標準 9 色パレットへの近似（RGB を最近傍色へ丸め込み）
- **レイヤーロック**: DXF フォーマットが非対応のため往復で失われます
- **レイヤー重ね順**: DXF は重ね順フィールドを持たないため往復で失われます
- **線幅**: 往復で保存されず既定値に戻ります
- **TEXT**: 位置・高さ・回転をマッピング。CJK を含む文字列も UTF-8 でそのまま保存・復元されます（DXF ヘッダ R2007 化に対応）。非標準的な位置基準（水平 Left 以外、または垂直 Baseline 以外）の TEXT はスキップされます
- **DIMENSION**: mcad の寸法は DXF へ export されません（DXF に対応するプリミティブがないため。スキップされた件数がステータスバーに表示されます）。`.mcad` 形式では通常どおり保存されます。DXF DIMENSION の import は M9 で対応予定です
- **CJK テキストの他ソフトでの表示**: mcad が書き出した CJK は他の CAD ソフトでは文字化けする場合があります（LibreCAD で実測）。DXF はフォント本体をファイルへ埋め込めず、受け取り側のフォント環境に依存するためです

## アーキテクチャ

Cargo ワークスペースで4つのクレートを管理し、依存方向は一方向のみです。

```
mcad/
├── crates/
│   ├── mcad-geom/  → GUI非依存の幾何プリミティブと計算
│   ├── mcad-core/  → ドキュメントモデル・undo/redo（mcad-geomに依存）
│   ├── mcad-io/    → ファイル保存/読込、DXF変換（mcad-coreに依存）
│   └── mcad-app/   → eguiアプリケーション本体（mcad-ioに依存）
```

| クレート | 役割 |
|---------|------|
| **mcad-geom** | 幾何プリミティブ型（`Point2`, `Vec2`, `LineSeg`, `Circle`, `Arc`, `Polyline`, `Shape`）と計算（最近点、距離、交点）。GUI非依存・純関数のみ |
| **mcad-core** | CADドキュメントモデル（`Document`/`Entity`/`Layer`）とコマンドパターンによる undo/redo |
| **mcad-io** | `.mcad`（JSON形式）の保存/読込と、`dxf`クレート経由のDXF入出力 |
| **mcad-app** | egui による GUI アプリ本体。ツール・ビューポート・スナップエンジン・レイヤーパネル・ファイル操作 |

レイヤー順は `mcad-app` → `mcad-io` → `mcad-core` → `mcad-geom` で、上位クレートは下位クレートへ直接依存できます（例: `mcad-app` は `mcad-core`・`mcad-geom` も直接利用）。禁止しているのは下位→上位の逆方向の依存のみです。

主な設計判断:

- **f64 ワールド座標**: CAD の座標精度が重要。f32 は大きな図面で誤差が蓄積するため、egui へ描画する境界でのみ f32 へ変換する
- **コマンドパターン undo**: スナップショット方式より省メモリで大図面でも成立。すべての変更は `Document::apply(Command)` 経由で行う
- **geom を GUI 非依存に分離**: 幾何計算を純関数としてテスト可能にし、将来の拘束ソルバー追加も容易にする
- **空間インデックスは省略**: 数千エンティティまでは全走査 + AABB カリングで対応する

## 開発

```bash
cargo build                                  # ワークスペース全体をビルド
cargo test --workspace                       # 全テストを実行
cargo clippy --workspace --all-targets       # lint チェック（警告ゼロを維持）
cargo fmt --all --check                      # 整形チェック
```

CI（`.github/workflows/ci.yml`）もこの3チェック（fmt / clippy / test）を実行します。すべての変更はこれらが通ってからコミットしてください。

GUI に関わる変更（ダイアログ・ビューポート・パネル等）は自動テストできないため、実ウィンドウでの手動スモークテストが必要です。

## フォント / ライセンス帰属

文書内のテキスト（Text エンティティ）で日本語などの CJK グリフを表示するため、
[Noto Sans JP](https://fonts.google.com/noto/specimen/Noto+Sans+JP) Regular をバイナリへ
埋め込んでいます。egui の既定フォントの後ろにフォールバックとして追加しているため、
UI ラベルや英数字の見た目は変わりません（egui の UI 可視文字列は ASCII 限定の方針を維持）。
