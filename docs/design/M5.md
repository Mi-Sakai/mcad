### M5: 編集操作の充実(v0.5.0)の設計

#### 設計判断

1. **変換はShapeのメソッドとして mcad-geom に置く**: `translated` に加えて `rotated(pivot, angle)` /
   `mirrored(axis_a, axis_b)` を追加する(`translated` に合わせた過去分詞・非破壊命名。
   2026-07-19 実装済み、タスク17)。app 層での座標いじりを禁止し、`Command::ModifyEntity` / `AddEntity` 経由を維持する
2. **複製は「選択集合 → AddEntity の Batch」**: 元エンティティは変更しない。undo 1回で複製全体が消える(Batch 原子性)。
   変位は **2クリック配置**(Ctrl+D で複製配置モードに入り、基準点→配置先をクリック指定)とする
   (2026-07-19 決定。固定ワールド変位は単位系未確立でスケール不定、グリッド1マス変位はズーム依存で
   非決定論的なため、CAD 慣行どおり基準点+配置先のクリック指定を採る)。詳細仕様:
   - Ctrl+D は選択集合が非空のときのみ配置モードへ入る(空なら ASCII ステータスメッセージ)
   - 1クリック目=基準点、2クリック目=配置先。どちらのクリックにもスナップが効く
   - 2クリック目までの間、`(カーソル - 基準点)` だけ平行移動した選択集合のプレビューを描画する(Document は変更しない)
   - 確定は `AddEntity` の Batch 1発。元エンティティのレイヤー・スタイルを複製し、幾何のみ `translated(delta)`。
     `NewIds.entities`(コマンド順)を新しい選択集合にする。`Err`(レイヤーロック等)はステータスバーへ
   - 基準点と配置先がほぼ同一(ピック許容量内)の場合は、見えない重複コピーを防ぐため確定せずキャンセル扱い
     (ASCII ステータスメッセージで通知)
   - Esc・ツール切替・ファイル操作・モーダル表示は配置モードを解除し、Document を変更しない。
     配置モード中は通常の選択クリック・矩形選択と共存させない(入力ゲートを明示する)
   - **2026-07-19 追記**: 移動もドラッグ方式から同じ2クリック配置へ変更(`M` キー、Placement 機構を
     `PlacementKind::Move` 種別で共用、ドラッグは矩形選択専用化)。掴み判定の厳しいドラッグ移動と、
     矩形選択のつもりが移動になる誤操作をなくし、移動にもスナップが効くようになる。確定は
     `ModifyEntity` の Batch(ID 不変)で、成功時は選択を維持する(複製と違い新 ID 選択にしない)。
     これに伴いタスク19のミラー起動キーは `M` から `Shift+M` へ変更する(2026-07-19 確定。設計判断4参照)。
3. **オフセットは対象を限定**: 線分・円・円弧は厳密解が単純。ポリラインの自己交差処理は複雑なため、
   M5 では「各セグメントの平行移動+隣接セグメントの交点接続」の単純方式とし、自己交差は仕様として許容(明記する)
4. **回転・ミラーの基準指定はツール化**(2026-07-19 全面確定。タスク19着手前に決定):
   - 起動キー: 回転 = `R`、ミラー = `Shift+M`(`M` は移動に使用済みのため。実装時は既存の
     `M` キー移動判定に `!shift` ガードを追加し、`Shift+M` で移動が誤起動しないようにする)
   - **回転**: 3クリック相対角方式(AutoCAD 流)。`R` → pivot(回転中心)クリック → 基準点クリック →
     回転先クリック。回転角 = `angle(pivot→回転先) − angle(pivot→基準点)`。2クリック目以降は
     カーソル追従でプレビュー(ゴースト)が相対角で回転する
     (2クリック方式(pivot 指定後、カーソル方向を絶対角として使う案)は不採用。図形の元の向きと
     ワールド +X 基準の絶対角が一致せず直感に反するため)
   - **ミラー**: 軸2点(A→B)のクリック指定。`Shift+M` → 軸点A → 軸点B。2クリック目までカーソル
     追従で鏡映プレビューを描画する
   - **共通仕様**:
     - 全クリックにスナップを適用する
     - プレビューは `Shape::rotated` / `Shape::mirrored` を使い、確定までは Document を変更しない
     - 確定は選択エンティティごとの `ModifyEntity` を1個の `Command::Batch` にまとめる
       (ID・選択集合は維持、複製と違い新規選択にしない)
     - 退化入力は確定せず拒否し、ASCII ステータスメッセージで通知する。この場合履歴(undo)は作らない。
       拒否ゲートは「その操作が意味を持つか」で判定する:
       - 回転の基準点 ≈ pivot(ピック許容量内): 基準方向が定義不能(絶対角に化ける)ため拒否
       - **(2026-07-19 追記)** 回転先 ≈ pivot(ピック許容量内): pivot からの方向が定義不能なため拒否
       - **(2026-07-19 追記)** 回転の正規化相対角(`atan2(cross, dot)` で求める符号付き `(-π, π]`)が
         ほぼゼロ: no-op の `ModifyEntity` と空の undo 履歴を作らないため拒否。相対角で判定するので、
         回転先が基準点と同一 ray・半径ちがい(距離は大きいが実角度ゼロ)も確実に弾け、pivot 近傍の
         大角度を距離で誤拒否することもない(当初の「基準点 = 回転先」= 距離ベース判定を置き換え)
       - ミラーの軸A ≈ 軸B(ピック許容量内): 軸が定義不能なため拒否
       - 複製・移動の基準点 ≈ 配置先(変位ゼロ、ピック許容量内): 見えない結果を防ぐため拒否
     - Esc・ツール切替・ファイル操作・モーダル表示・undo/redo で状態解除する(既存 Placement 機構と同じ規約)
     - 選択が空のときは起動せず ASCII ステータスメッセージを表示する
     - 実装はタスク18で導入した `PlacementKind` ステートマシンへのバリアント追加で行う
5. **オフセットのUXと退化仕様**(2026-07-19 確定。タスク20着手前に決定。設計判断3の詳細化):
   - 起動キー: `O`(Select 内)。**対象は単一エンティティ限定** — 選択集合がちょうど1個のときのみ
     起動する(空・複数なら ASCII ステータスメッセージ。通過点1点に対して複数対象の距離が
     一意に定まらないため。AutoCAD も1対象ずつの繰り返し操作)
   - **距離・側の指定は両対応**(2026-07-19 ユーザー確定):
     - **通過点方式(既定)**: `O` → 通過点を1クリック。距離 = 対象からクリック点までの最短距離、
       側 = クリック点のある側。クリックにはスナップが効く
     - **数値入力方式**: ツールパネルの距離入力欄(ASCII ラベル、正の有限値のみ受理)に値が
       入っている場合、クリックは**側の決定のみ**に使い、距離は入力値を用いる。
       欄が空(または 0・非数)なら通過点方式にフォールバックする
   - **側の定義**: クリック点から対象への最近点を求め、最近点→クリック点の向きを側とする。
     円・円弧はクリック点が中心より外なら外側(r+d)、内なら内側(r−d)。
     線分・ポリラインは最近セグメントの法線符号で決める
   - **プレビュー**: モード中はカーソル追従で「いま確定した場合の結果」をゴースト描画する
     (入力欄に値があれば固定距離+カーソル側、なければカーソルを通過点とみなす)。
     確定までは Document を変更しない
   - **確定**: 元エンティティは変更せず、オフセット結果を `AddEntity`(レイヤー・スタイルは
     元を複製)で追加する。undo 1回で消える。確定後は**元エンティティの選択を維持**して
     モード終了する(同一元からの等間隔連続オフセットを `O` 再押下で繰り返しやすくするため。
     複製と違い新 ID を選択にしない)
   - **幾何(mcad-geom に実装)**: 線分 = 法線方向へ平行移動。円・円弧 = 半径 ± d(中心・角度
     不変)。ポリライン = 各セグメントを平行移動し、隣接セグメントは無限直線の交点で接続
     (設計判断3の単純方式、閉ポリラインは末尾-先頭も同様)。自己交差は仕様として許容(設計判断3)
   - **(2026-07-19 追記、Codex adversarialレビュー反映)** ポリラインの接続規則の詳細:
     - **マイター上限**: 交点接続は、頂点から交点までのマイター長が `MITER_LIMIT × distance`
       (SVG/Canvas の慣行に合わせ MITER_LIMIT = 4.0)を超えたらベベルへフォールバックする。
       EPS 平行判定だけでは浅い角で交点が距離の数百万倍へ飛び、確定後に図面が見かけ上
       空になる(fit で吹き飛ぶ)ため
     - **ベベルは平行移動後の2端点を両方残す**(頂点は1→2個に増える。「頂点数維持」は撤回)。
       中点1点への畳み込みは 180°折返しで元頂点そのものに退化し、オフセットでもベベルでも
       ない形状になるため。直線継続(2端点がほぼ一致)のみ1頂点に畳んでよい
   - **(2026-07-19 追記、同上)** 円弧の通過点距離・側は**放射方向で定義**する:
     距離 = `| |通過点−中心| − r |`、側 = 通過点が中心より外か内か(全円と同一の規則)。
     クリック角が掃引範囲外でも放射定義で受け付ける(結果は同心弧のため、掃引外クリックでは
     結果が通過点を通らないことを API doc に明記する)。弧上の最近点距離(`distance_to`)を
     使うと端点近傍で角度方向成分が混入し「通過点を通る」契約と矛盾するため
   - **退化入力の拒否**(回転・ミラーと同じ規約: 確定せず ASCII メッセージ、undo 履歴を作らない):
     - 円・円弧の内側オフセットで `d >= r`(半径が消滅・反転)
     - 距離ゼロ(通過点が対象上ピック許容量内、または入力欄が 0)— no-op 防止
     - 対象がゼロ長(退化した線分・ポリライン)で法線が定義不能
   - Esc・ツール切替・ファイル操作・モーダル表示・undo/redo で状態解除、スナップ適用などの
     共通規約は設計判断4の共通仕様に従う
   - **(2026-07-19 追記、Codex adversarialレビュー反映)** 距離入力欄フォーカス中は、ツール切替
     ショートカットだけでなく**アプリの全ドキュメント系ショートカット**(undo/redo・Ctrl+D・
     Delete・ファイル操作等)をゲートする。編集中の Ctrl+Z がドキュメントを undo するなどの
     テキスト入力とショートカットの競合を防ぐ
   - **相乗り修正**: `Arc::mirrored` の退化軸ガード(軸2点がほぼ同一なら無変換で `self` の
     クローンを返す仕様として明文化・テスト固定。UI 側は既に拒否済みだが、geom は tcad からも
     直接使われるため防御を入れる)

#### 検収基準(M5完了の定義)

- 選択→Ctrl+Dで複製され、undo 1回で複製全体が消える
- 回転・ミラーが基準指定つきで動き、スナップが基準点指定にも効く
- 線分・円・円弧のオフセットが数学的に正しい(テストで固定)
- 全操作がレイヤーロックを尊重し、失敗はステータスバーに出る
- fmt / clippy / workspace test 通過、GUI 変更は手動スモークテストを記録する
