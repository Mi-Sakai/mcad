# mcad 仕様書(v1.0.0)

mcad v1.0.0 が**利用者から見て何をするか**と、**保存・出力の約束**をまとめた文書。実装言語に依存しない
形で書き、別の言語で作り直すとき(移植)の基準と、受け入れテストの元にする。

- 対象は v1.0.0(`.mcad` 形式 v9)。v1.0.0 以降に振る舞いを変えたら、実装と同じコミットで本書を直す。
- 設計の理由・経緯・却下した案は書かない。それらは [`DESIGN.md`](../DESIGN.md) と [`docs/design/`](./design/)
  にある。版ごとの変更は [`CHANGELOG.md`](../CHANGELOG.md)。
- 本書を書いた時点で文書と実装が食い違っていた箇所は、**実装に合わせて**書いた。
- 実装の型名・関数名は、ファイル形式のキー名など外部から見える契約に要るものだけを書く。仕様の節と
  実装の場所の対応は[付録 C](#c-仕様の節と実装の場所の対応)にまとめる。

**表記**

- UI のラベル・メッセージは画面に出る文字列どおりに「」または `コード体` で書く。日本語の領域と
  英語の領域がある(9.1 節)。
- キーは `Ctrl+S` のように書く。macOS では `Ctrl` が `Cmd` になる(GUI ライブラリの command 修飾)。
- 角度は特に断らない限り **+X 軸から反時計回り(CCW)**。画面の入力・表示は度、ファイルはラジアン。

## 1. 目的と範囲

### 1.1 mcad が何をするか

mcad は個人用の 2D CAD である。機械製図の図面を 1 枚、作図から出力まで mcad だけで仕上げられることを
v1.0.0 の範囲とする。

- 図形(点・線分・円・円弧・ポリライン・矩形・正多角形・構築線)と文字を描く。
- 編集する(選択・移動・複製・回転・ミラー・オフセット・トリム・延長・フィレット・面取り・分割・結合・
  分解・削除・グリップ編集)。
- 寸法(長さ・半径・直径・角度・座標)を、寸法補助記号・サイズ公差・表記の種類つきで記入する。
- 表と部品欄、図面枠と表題欄を置く。
- 線分・円・円弧に幾何拘束を付け、編集に追従させる。
- `.mcad`(JSON)で保存・読込する。DXF を読み書きする。SVG・PDF へ実寸で出力する。

### 1.2 範囲外

v1.0.0 が持たないもの(14 章に一覧):

- 3D(Z 軸・ソリッド)、楕円・スプライン、ハッチング
- 幾何公差・表面性状・溶接記号・風船・引出線
- グループ・ブロック(DXF の `INSERT`)
- 文字の揃え(中央・右揃え)、複数行の文字
- 駆動寸法(寸法値を変えると形が動く)、寸法と図形の関連付け
- 紙空間・複数レイアウト、複数図面の同時オープン(タブ)
- メニューバー・リボン(操作はキーと右パネル・上部パネルで行う)
- レイヤーの改名、エンティティの色の個別指定(UI から。4.4 節)

## 2. 用語

| 用語 | 意味 |
|---|---|
| ワールド座標 | 図形の座標。単位は mm、y 軸は上向き。倍精度浮動小数点で持つ |
| 紙 mm | 用紙の上での長さ(mm)。文字高さ・寸法スタイル・表の寸法・線幅・図面枠はこの単位で持つ |
| 尺度 | 紙:モデルの整数比(例 `1:2` は紙 1 mm がモデル 2 mm)。図面に 1 つ |
| `k` | 紙 1 mm あたりのワールド mm(= 尺度の `den / num`)。紙 mm の量をワールドへ置くときに掛ける |
| エンティティ | 図面に保存される要素 1 つ(図形・構築線・文字・寸法・表) |
| 図形 | 点・線分・円・円弧・ポリライン。矩形・正多角形・アイソメ円は図形の組として作られる |
| 構築線 | 両方向へ無限に延びる作図補助の直線(5.5 節) |
| 寸法 | 長さ・半径・直径・角度・座標の 5 種類のエンティティ(6 章) |
| 表 | 罫線とセルを持つエンティティ。種類は「表」と「部品欄」の 2 つ(7 章) |
| 部品欄 | 部品の一覧を書く表。1 図面に 1 つまで。コードとファイル上の名前は BOM(`Bom`) |
| 図面枠・表題欄 | 図面メタデータから描かれる枠と欄。エンティティではなく、選択・スナップの対象にならない |
| レイヤー | エンティティの所属先。色・線種・線幅・表示・ロック・重ね順を持つ |
| 既定レイヤー | 名前 `"0"` のレイヤー。文書に必ず 1 つあり、削除できない |
| カレントレイヤー | 新しいエンティティを置くレイヤー(自動割り当てがある。4.3 節) |
| ByLayer | エンティティのスタイル(色・線幅・線種)を指定せず、レイヤーの値に従うこと |
| 選択集合 | 選択中のエンティティの集合 |
| 基点 | 作図・配置中に「直前に確定した点」。相対の数値入力・直交・極トラッキング・垂線/接線スナップの基準 |
| スナップ | カーソルを図形の特徴点・グリッドへ吸着させること(5.3 節) |
| 拘束 | 線分・円・円弧に付ける幾何の条件(8 章)。エンティティではない |
| undo 単位 | `Ctrl+Z` 1 回で戻る範囲。UI の 1 操作が 1 単位 |
| 上部パネル | ウィンドウ上端のパネル。ファイル名・ツール・トグル状態・ツールの入力欄・通知・キー凡例を並べる |
| ステータスバー | 上部パネルの 1 行目の右側に一時的に出る通知(赤字)。文書ではこう呼ぶ(下端の専用バーは無い) |
| 右パネル | ウィンドウ右側のパネル。レイヤー・スタイル・寸法・表・拘束・図面・寸法スタイルの各セクション |
| 非対称往復 | DXF へ書いて読み戻すと、元のエンティティの種類に戻らない経路(12 章) |

## 3. 座標・単位・尺度・用紙

### 3.1 ワールド座標

- 1 ワールド単位 = 1 mm。内部で単位を切り替える仕組みは無い。ファイルには単位として `"Millimeter"` を
  記録する(現在これ以外の値は無い)。
- y 軸は上向き。画面(y 下向き)への反転は表示の境界でだけ行う。
- 座標は倍精度(f64)で持ち、画面描画の境界でだけ単精度へ落とす。
- 非有限(NaN・無限大)の座標・寸法は、作図・読込のどの経路でも拒否する。

### 3.2 尺度

- 尺度は**紙:モデル**の正の整数の対 `num:den`。各項は 1〜1,000,000。既約化しない(`2:5` と `4:10` は別の値として
  保存・表示する)。中間の尺度は整数比で表す(1:2.5 は `2:5`)。既定は `1:1`。
- `k = den / num`。紙 mm の量 `x` はワールドで `x × k` になる。
- 右パネル「図面」の「尺度:」コンボの選択肢は次の 18 個と「カスタム」。カスタムでは `num:den` を入力して
  「適用」を押す。

  `50:1` `20:1` `10:1` `5:1` `2:1` `1:1` `1:2` `1:5` `1:10` `1:20` `1:50` `1:100` `1:200` `1:500` `1:1000`
  `1:2000` `1:5000` `1:10000`

- 尺度を変えても図形の座標は変わらない。変わるのは紙 mm で持つもの(文字・寸法の注記・表・図面枠・線幅・
  線種のピッチ)のワールドでの大きさと、出力の縮尺である。

### 3.3 紙 mm で持つもの

| 量 | 単位 | ワールドでの大きさ |
|---|---|---|
| 文字の高さ | 紙 mm | `height × k` |
| 寸法スタイル(文字高さ・矢の長さ・すきま等) | 紙 mm | `× k` |
| 表の列幅・行高さ・文字高さ | 紙 mm | `× k`(位置 `anchor` はワールド) |
| 線幅 | 紙 mm | 画面ではズームに比例(9.3 節)、出力ではそのまま |
| 線種のダッシュの長さ | 紙 mm | 同上 |
| 図面枠・表題欄 | 紙 mm | `× k`(用紙ごとワールドへ置く) |

### 3.4 用紙

- 用紙は A 列の 5 種類(延長サイズは無い)。

  | 用紙 | 短辺 × 長辺 [mm] |
  |---|---|
  | A0 | 841 × 1189 |
  | A1 | 594 × 841 |
  | A2 | 420 × 594 |
  | A3 | 297 × 420 |
  | A4 | 210 × 297 |

- 向きは「横」(長辺が横。既定)と「縦」。縦はどの用紙でも選べる。
- 紙空間は持たない。用紙は**用紙の左下をワールドの原点 `(0,0)` に置いた矩形**として、ワールドに
  `(用紙幅 × k) × (用紙高さ × k)` の大きさで重なる。
- 画面には用紙の外形(用紙縁)を灰色で描く。用紙縁は出力しない。
- 新規図面の用紙・向き・尺度・表題欄の様式は `config.json` の既定値から作る(13 章)。右パネルで図面の
  用紙・向き・尺度・様式(A/B/C)を変えると、その値が次の新規図面の既定になる。

### 3.5 図面枠と表題欄

図面枠と表題欄は図面メタデータから毎回描く派生描画で、エンティティではない(選択・移動・スナップ・
DXF 出力の対象外)。右パネル「図面」の「図面枠を表示」で表示を切り替える(新規図面の既定は OFF)。

- **輪郭線**: 用紙の全周から 10 mm 内側の矩形。線幅 0.5 mm。
- **表題欄**: 輪郭線の右下隅に、下辺と右辺を輪郭線に接して置く。外枠 0.5 mm、内部の区切り 0.13 mm。
  欄の文字は左詰め(セル左端から 1.5 mm)・垂直はおおよそ中央。空の欄は描かない。
- **様式**(幅 × 高さ。段は上から下、セルは左から右。幅 mm と項目):

  | 様式 | 大きさ | 1 段目 | 2 段目 | 3 段目 |
  |---|---|---|---|---|
  | A | 170 × 30 | 図面名称 100・図面番号 70(高さ 15) | 作成者 40・作成日 30・尺度 25・投影法 25・用紙 25・改訂記号 25(高さ 15) | — |
  | B(既定) | 120 × 25 | 図面名称 70・図面番号 50(高さ 12.5) | 作成者 25・作成日 25・尺度 20・投影法 20・用紙 15・改訂記号 15(高さ 12.5) | — |
  | C | 170 × 40 | 図面名称 170(高さ 15) | 図面番号 70・用紙 25・改訂記号 25・予備 50(高さ 12.5) | 作成者 40・作成日 30・尺度 25・投影法 25・予備 50(高さ 12.5) |

  文字高さは図面名称・図面番号が 5.0 mm、それ以外が 3.5 mm。予備欄は空欄のまま描く。
- **ユーザー定義様式**(`Custom`): 段とセル(幅・項目・文字高さ)を自由に持つ様式。`.mcad` に保存・読込
  できるが、**作る・編集する UI は無い**(右パネルでは「ユーザー定義」と表示する)。新規図面の既定には
  ならない。
- **欄の値**: 図面番号・図面名称・投影法・作成者・作成日・改訂記号は「表題欄を編集…」ダイアログ(7.4 節)で
  記入する。尺度欄は `num:den`、用紙欄は `A4`(縦は `A4 縦`)を図面メタデータから自動で書く。投影法は
  「第三角法」(既定)/「第一角法」。

## 4. 図面の構成

### 4.1 図面が持つもの

1 つの図面(文書)は次を持つ。`.mcad` に保存されるのはこれだけである(11 章)。

- 図面メタデータ: 単位・尺度・用紙・向き・表題欄の様式・表題欄の値・図面枠の表示・「部品欄を使う」
- レイヤーの一覧とカレントレイヤー
- エンティティの一覧(追加順)
- 寸法スタイル(文書に 1 つ。6.7 節)
- 拘束の一覧(8 章)

保存しないもの: undo/redo の履歴、選択、表示位置・ズーム、作図ツールの状態、トグル類(13 章の設定)。

### 4.2 レイヤー

**属性**

| 属性 | 内容 |
|---|---|
| 名前 | 文字列。重複してもよい(名前で探すときは最初に見つかったもの) |
| 色 | 24 bit RGB |
| 線種 | 実線・破線・一点鎖線・二点鎖線(4.4 節) |
| 線幅 | 紙 mm(0.05〜5.0) |
| 表示 | OFF のレイヤーのエンティティは描かず、選択・スナップ・出力の対象にもしない |
| ロック | ON のレイヤーのエンティティは追加・変更・削除できない(下記) |
| 重ね順 | 整数。大きいほど手前に描く。値の間隔に意味は無い |

**右パネル「レイヤー」**

- 列は「現在」(カレントにするラジオボタン)・「色」・「表示」・「ロック」・「名前」・「線幅」・「線種」・「操作」。
  行は重ね順で、手前のレイヤーが上。
- 「操作」の「前面」「背面」は、そのレイヤーを最前面・最背面へ移す(端の行では押せない)。「x」はレイヤーを
  削除する。
- 「+ レイヤー追加」は名前 `Layer {n}`(`n` は追加前のレイヤー数)のレイヤーを最前面に足す。色は 6 色の
  パレット(赤・緑・青・黄・紫・水色の順)を巡回する。
- レイヤーの**改名は UI から行えない**。
- レイヤーを削除できるのは、既定レイヤー `"0"` でなく、カレントでもなく、エンティティを 1 つも持たない
  ときだけ。それ以外は拒否してステータスバーに理由を出す。
- 色・表示・ロック・重ね順・線幅・線種の変更はロック中のレイヤーにも効く(ロックが禁じるのはそのレイヤー上の
  エンティティの変更だけ)。どれも undo 1 回で戻る。

**ロック**

- ロック中のレイヤーのエンティティも、表示されていれば選択できる。
- 選択集合にロック中のエンティティが混ざった移動・削除などは、操作全体が失敗し何も変わらない。理由
  (`layer is locked: …` を含む文言)をステータスバーに出す。黙って一部だけ動かすことはしない。
- ロック中のレイヤーのエンティティは、拘束の求解でも動かさない(8.3 節)。

### 4.3 新規図面のレイヤーと自動割り当て

**新規図面**(起動時・`Ctrl+N`)は次の 7 枚で始まる。上が手前。カレントは「外形線」。

| 名前 | 色 | 線種 | 線幅 [mm] | 重ね順 |
|---|---|---|---|---|
| 文字 | 白 | 実線 | 0.18 | 6 |
| 寸法線 | 白 | 実線 | 0.18 | 5 |
| 外形線 | 青 (90,140,255) | 実線 | 0.35 | 4 |
| 破線 | 緑 (80,200,120) | 破線 | 0.35 | 3 |
| 中心線 | 赤 (230,80,80) | 一点鎖線 | 0.13 | 2 |
| 構築線 | 水色 (70,210,210) | 実線 | 0.13 | 1 |
| `0`(既定レイヤー) | 白 | 実線 | 0.35 | 0 |

- 「0」以外の 6 枚は削除してよい。ファイルを読み込んだときは足さない。
- **自動割り当て**: 次のツールで作ったエンティティは、表の名前のレイヤーが図面にあればそこへ、無ければ
  カレントレイヤーへ置く。レイヤーを自動で作ることはしない。

  | 作るもの | 置き先のレイヤー名 |
  |---|---|
  | 寸法(5 種類すべて) | `寸法線` |
  | 文字・表・部品欄 | `文字` |
  | 構築線 | `構築線` |

  それ以外のツール(図形・オフセットの結果など)はカレントレイヤーへ置く。構築線をオフセットして作る
  線分(5.5 節)もカレントレイヤー。

### 4.4 スタイル(色・線幅・線種)

- エンティティは色・線幅・線種をそれぞれ「指定なし(ByLayer)」か個別の値で持つ。指定なしはレイヤーの値に従う。
- 右パネル「選択中のスタイル」で、選択中のエンティティの「レイヤー:」「線幅:」「線種:」を変えられる。
  線幅と線種は「ByLayer」を選ぶとレイヤーの値へ戻す。複数を選んだときは全件へ undo 1 回で適用し、値が混ざって
  いれば「混在」と出す。
- **色の個別指定は UI から行えない**。個別の色を持つエンティティは、ファイル(手で書いた `.mcad`・DXF)から
  だけ生まれる。表示・出力はその色で行う。
- **線幅**: UI で選べるのは ISO 128 系列の 9 値 `0.13` `0.18` `0.25` `0.35` `0.5` `0.7` `1.0` `1.4` `2.0`(mm)。
  ファイルからは 0.05〜5.0 mm の任意の値を受け付ける(範囲外・非有限は読込エラー)。既定 0.35。
- **線種**と、そのダッシュの並び(紙 mm。線・空白の順に繰り返す):

  | 線種 | UI の名前 | パターン [mm] |
  |---|---|---|
  | `Continuous` | 実線 | — |
  | `Dashed` | 破線 | 3.0, 1.5 |
  | `DashDot` | 一点鎖線 | 6.0, 1.2, 0.6, 1.2 |
  | `DashDotDot` | 二点鎖線 | 6.0, 1.2, 0.6, 1.2, 0.6, 1.2 |

- 寸法は線種の指定にかかわらず常に実線で描く。

### 4.5 エンティティの種類と属性

| 種類 | 属性(ファイル上のキー) | 備考 |
|---|---|---|
| 点 | `x`, `y` | 画面では小さな印で描く |
| 線分 | 始点 `a`・終点 `b` | 長さ 0 も保存できる |
| 円 | 中心 `center`・半径 `radius` | 半径は 0 以上 |
| 円弧 | 中心・半径・開始角 `start_angle`・終了角 `end_angle`(ラジアン) | 開始角から終了角へ CCW に描く |
| ポリライン | 頂点列 `vertices`・閉じているか `closed` | 頂点は 1 つ以上。辺は直線のみ(円弧の辺は無い) |
| 構築線 | 基点 `base`・単位方向 `dir` | 5.5 節 |
| 文字 | 基準点 `anchor`(ベースライン左端)・文字列 `content`・高さ `height`(紙 mm)・回転 `angle`(ラジアン) | 1 行。空文字列は不可。7.1 節 |
| 長さ寸法 | 計測点 `p1`・`p2`、寸法線のずれ `offset`、向き `direction`、補助線の傾き `ext_angle`、注記 | 6 章 |
| 半径寸法 | 中心・半径・引出線の角度 `leader_angle`・注記 | |
| 直径寸法 | 中心・半径・寸法線の角度 `angle`・注記 | |
| 角度寸法 | 頂点 `vertex`・辺上の点 `p1`・`p2`・弧の半径 `arc_radius`・注記 | |
| 座標寸法 | 原点 `origin`・計測点 `feature`・引出線端 `leader_end`・軸 `axis`(`X`/`Y`)・注記 | |
| 表 | 種類 `kind`・左下 `anchor`・列幅・列の揃え・行高さ・文字高さ・セル | 7.2 節 |

各エンティティは所属レイヤーとスタイル(4.4 節)を持つ。

- **描画順**: レイヤーの重ね順の昇順(奥から)に描き、同じレイヤーの中ではエンティティの追加順に描く。
- **寸法は非関連**: 寸法は自分の定義点だけを持ち、測った図形とはつながっていない。図形を動かしても
  寸法は動かず値も変わらない。寸法自身の点を動かせば値は追従する(値は常に定義点から計算する)。

### 4.6 undo/redo

- `Ctrl+Z` で取り消し、`Ctrl+Y` または `Ctrl+Shift+Z` でやり直す。回数の上限は無い。
- UI の 1 操作が undo 1 単位。複数のエンティティにまたがる操作(選択集合の移動・削除、フィレットの 3 図形、
  右パネルでの複数寸法の一括変更、拘束の追従など)も 1 単位。
- 複数の変更からなる操作は**原子的**: 途中の 1 つでも失敗すれば操作全体を取り消し、図面は操作前のまま。
- 図面を変えない操作(値が同じ変更)は undo 単位を作らない。
- **未保存の印**: ウィンドウタイトルは `mcad - {ファイル名}{*}`(未保存の変更があれば `*`、ファイル名が無ければ
  `Untitled`)。上部パネルの `File:` も同じ。undo/redo で保存時点の状態へ戻ると `*` は消える。
- 読込・新規作成の直後は履歴が空で、読込そのものを `Ctrl+Z` で戻すことはできない。

### 4.7 失敗の扱い

- 図面を変える操作が失敗したときは、図面を変えず、理由をステータスバーへ出す。主な理由:
  レイヤーのロック、拘束が解けない(8 章)、部品欄が既にある(7.3 節)、図形として不正(非有限・負の半径・
  空のポリライン等)。
- ステータスバーの通知は通常 10 秒、ファイル操作(開く・保存・DXF の取込/書出)の結果は 15 秒で消える。

### 4.8 新規作成・読込で消える状態

新規作成・`.mcad` を開く・DXF を取り込むと、次をリセットする。

- ツールを選択ツールへ戻し、選択集合・配置中の移動/複製・オフセット・文字ドラッグ・グリップドラッグ・拘束ツールの
  選んだ対象・選択中の拘束を捨てる。
- 上部パネルの入力欄: オフセット距離・フィレット半径・面取り距離・補助線の傾き・拘束の値・文字列を空に、
  文字の高さを `3.5`、正多角形の辺数を `6` に戻す。
- スナップ・極トラッキングのマーカー、表題欄ダイアログ、尺度のカスタム入力、寸法パネルの編集中の値。
- 読込のあとは図面全体が収まるようにズームする(空の図面なら既定の表示へ戻す)。

トグル(スナップ・直交・極トラッキング・紙基準表示・グリッド)と設定は消えない。

## 5. 作図と編集

### 5.1 ツールの切り替えと共通の規則

- ツールはキーで切り替える(キーの一覧は[付録 A](#a-キーの一覧))。上部パネルの `Tool:` に現在のツール名
  (`Select` `Point` `Line` `Circle` `Arc` `Iso Circle` `Polyline` `Rectangle` `Polygon` `Construction Line`
  `Text` `Table` `Linear Dim` `Radial Dim` `Diameter Dim` `Angular Dim` `Ordinate Dim` `Trim` `Extend` `Fillet`
  `Chamfer` `Split` `Constraint`)を出す。
- ツールのキーは修飾なし(または `Shift` 併用)のときだけ効く。`Ctrl` 併用はファイル操作・undo などに使う。
  モーダルダイアログが開いている間と、テキスト入力欄にフォーカスがある間は、ツールの切り替えキーを受けない。
- 作図ツールへ切り替えると選択集合を空にする。切り替えは進行中の配置(移動・複製)・オフセット・拘束ツールの
  選んだ対象を捨てる。同じツールのキーを押し直すと、そのツールを初期状態から始め直す。
- `1`(点ツール)への切り替えは選択ツールからだけ効く。作図ツールの使用中は数字キーが数値入力(5.2 節)に
  使われ、数値入力を受けないツールでは何も起きない。
- 作図ツールは確定後も同じツールのまま続けて描ける(連続作図)。確定に失敗すると理由をステータスバーに出す。
- 新しいエンティティはカレントレイヤーへ置く(自動割り当ては 4.3 節)。スタイルはすべて ByLayer。
- **取り消し**: `Esc` は作図中の状態を捨てて選択ツールへ戻る(どの段階でも)。例外は 2 段階のもの: 構築線と文字は
  1 回目で最初の段階(基点・基準点の待ち)へ戻り、2 回目で選択ツールへ戻る。拘束ツールは 1 回目で選んだ対象を捨て、
  2 回目で終える。数値入力の欄が開いていれば、1 回目の `Esc` は欄を閉じるだけ。

**作図ツール**

| ツール | キー | 入力の手順 | 結果・規則 |
|---|---|---|---|
| 点 | `1` | クリック 1 回 | 点 1 つ |
| 線分 | `L` | 始点 → 終点。以後クリックごとに前の終点から次の線分 | 線分は 1 本ずつ別のエンティティ(連続線分)。`Esc` で連続を終える |
| 円 | `C` | 中心 → 円周上の点 | 半径 = 2 点の距離 |
| 円弧 | `A` | 始点 → 通過点 → 終点 | 3 点を通る円弧。3 点が一直線に近いと 3 点目を無視して待つ |
| ポリライン | `P` | クリックで頂点を足し、`Enter` で確定(2 点以上) | 開いたポリライン。頂点が 3 つ以上あるとき始点をクリックすると閉じて確定する(始点への吸着はスナップによる)。直前の頂点と同じ点のクリックは無視する |
| 矩形 | `Shift+P` | 隅 → 対角の隅 | 軸に平行な閉じたポリライン。等測グリッド中も軸平行。幅か高さが 0 なら拒否 |
| 正多角形 | `Shift+C` | 中心 → 点 Q | 閉じたポリライン。辺数は上部パネル `Sides:`(3〜64、既定 6)。`Tab` か上部パネル `Polygon mode:` で `Inscribed`(Q が頂点)/`Circumscribed`(Q が辺の中点)を切り替える |
| 構築線 | `Shift+L` | 基点 → 通過点。以後同じ基点から通過点ごとに 1 本 | 5.5 節 |
| アイソメ円 | `I` | 中心 → 半径の点 | 5.6 節 |
| 文字 | `T` | 7.1 節 | |
| 表・部品欄 | `K` | 7.2・7.3 節 | |
| 寸法 | `D` `Shift+D` `G` `Shift+G` `Shift+V` | 6 章 | |

### 5.2 数値入力

点を受け付けるツールの使用中と、選択ツールの移動・複製の配置中は、`0`〜`9`・`.`・`-`・`@` を打つとカーソルの横に
入力欄が開く(AutoCAD の動的入力に相当)。`Enter` で確定した点は、その位置をクリックしたのと同じに扱う。

- **対象**: 点・線分・円・円弧・ポリライン・アイソメ円・矩形・正多角形・構築線、文字(アンカーを置く前だけ。
  置いた後は数字キーが上部パネルの `Text`・`H` 欄へ入る)、移動・複製の配置。寸法・トリム・延長・フィレット・
  面取り・分割・表・回転・ミラーは対象外。
- **書式**:

  | 書式 | 意味 | 基点 |
  |---|---|---|
  | `x,y` | 絶対座標 | 要らない |
  | `@dx,dy` | 基点からの相対 | 要る |
  | `L<A`(`@L<A` も同じ) | 基点から長さ `L`、角度 `A` 度(+X から CCW) | 要る |
  | `L` | 基点からカーソルの方向へ長さ `L`(極トラッキングが吸着中はその方向) | 要る(方向も) |

- **基点**: 線分・ポリライン・円弧・矩形・正多角形・構築線では直前に確定した点(矩形は 1 隅目、正多角形と円・
  アイソメ円は中心、構築線は基点)、移動・複製は基準点。最初の点を置く前と、点ツール・文字ツールには基点が
  無いので `x,y` だけを受ける。矩形の 2 隅目に `@w,h` を打てば幅と高さを直接指定できる。
- **数値**: `[+-]?(数字列[.数字列?] | .数字列)` だけを受ける。指数表記・`inf`・`nan` は誤り。空白は文字列全体の
  前後だけ無視し、中に空白があれば誤り。全角の ASCII 文字と数学のマイナス記号(U+2212)は半角へ寄せる。
  負の長さは逆向き(`-10<0` は `10<180` と同じ点)。書式に使わない文字も欄に残し、確定時に誤りとする。
- **確定・取り消し**: `Enter` で確定する。空のまま `Enter` を押すと、ツールの通常の `Enter`(ポリラインの確定等)に
  なる。`Esc` の 1 回目は入力欄を閉じるだけ。入力欄が開いている間、打ったキーはツールの切り替えや削除に使われない。
- **入力値にはスナップ・直交・極トラッキングを掛けない**。入力中はその点のプレビューを出す。
- **誤りのメッセージ**(ステータスバー):
  - `Numeric input: use x,y  @dx,dy  length<angle  or length`(書式の誤り)
  - `Numeric input: value out of range`(非有限)
  - `Numeric input: no base point yet - enter absolute x,y`(基点が無い)
  - `Numeric input: move the cursor away from the base point to set the direction`(`L` で方向が決まらない)

### 5.3 スナップ

- `F3` で全体を ON/OFF する(既定 ON)。種類ごとの ON/OFF は上部パネル「Snap types」メニューのチェックボックスで
  行い、`config.json` に保存する。
- 探索半径は画面 12 px。半径内の候補から**優先度の高い種類**を選び、同じ順位ではカーソルに最も近いものを選ぶ。
  候補が無ければスナップしない(カーソルの位置を使う)。採用した点に種類ごとの形のマーカーを出す。
- **種類と優先度**(上ほど優先。同じ行は同順位):

  | 順位 | 種類(メニューの名前) | 候補 | 既定 |
  |---|---|---|---|
  | 1 | 端点(`Endpoint`) | 点、線分・円弧の両端、ポリラインの頂点、文字の基準点。作図中のツールの確定済みの頂点も含む | ON |
  | 2 | 交点(`Intersection`) | 図形どうし・構築線との交点 | ON |
  | 3 | 中点(`Midpoint`) | 線分・ポリラインの各辺(閉じ辺を含む)の中点。円弧の中点は候補にしない | ON |
  | 4 | 中心(`Center`)・四半円点(`Quadrant`) | 円・円弧の中心、円の 0°/90°/180°/270° の点(円弧はその範囲にあるもの) | ON |
  | 5 | 垂線(`Perpendicular`)・接線(`Tangent`) | 基点から線分へ下ろした垂線の足(線分の上だけ)、基点から円・円弧への接点 | ON |
  | 6 | 仮想交点(`Virtual intersection`) | 線分・ポリラインの辺の延長どうし、延長と円・円弧の交点。延長部分を点線で示す | ON |
  | 7 | 近接点(`Nearest`) | 図形・構築線の上でカーソルに最も近い点 | **OFF** |
  | 8 | グリッド(`Grid`) | 表示中のグリッドの格子点(等測グリッドでは等測の格子点) | ON |

- 垂線・接線は基点のある段階(作図の 2 点目以降)だけ候補になる。
- 対象は表示中のレイヤーの図形・構築線と文字の基準点だけ。寸法・表・図面枠・表題欄は候補を出さない。
- **トリム・延長・フィレット・面取りのクリックはスナップしない**(クリックの位置が「残す側・伸ばす端」を表す
  ため、素のカーソル位置を使う)。ホバー時のマーカーも出さない。
- **分割**(`B`)は、`F3` が ON のとき対象の図形の上の中点・交点・中間の頂点だけに吸着する(両端・閉じた
  ポリラインの始点は割れないので候補にしない)。ホバー時に、実際に割られる点をマーカーで示す。
- グリップのドラッグ(5.10 節)にもスナップが効くが、掴んだ図形自身へは吸着しない。

### 5.4 直交モードと極トラッキング

- **直交モード**(`F8`、既定 OFF): 基点から水平・垂直のうち近い方へ点を拘束する。等測グリッド(`F5`)のときは
  30°・90°・150° の最も近い軸へ拘束する。
- **極トラッキング**(`F10`、既定 OFF): 基点からの方向が刻み角の倍数から 3° 以内なら、その方向へ吸着する。
  刻み角は上部パネルのコンボで `15°`(既定)/`30°`/`45°`/`90°`。基準は常に +X 軸(等測グリッドでも同じ)。
  吸着中は基点から点線と角度を表示する。上部パネルに `Polar: ON (15°)` のように出す。
- 直交モードと極トラッキングは排他。片方を ON にするともう片方は OFF になる。
- 優先順位は **スナップ > 直交 > 極トラッキング**。スナップの候補があればそれを使い、直交・極は掛けない。
- 効くツール: 線分・ポリライン・円弧・矩形・正多角形・構築線(基点のある段階)。円・文字・寸法・トリム等・
  移動/複製/回転/ミラーの配置には効かない。例外として長さ寸法は、向きが整列のとき直交モードで近い軸へ倒れる
  (6.2 節)。

### 5.5 構築線

- `Shift+L`。基点 → 通過点の 2 クリックで 1 本確定し、同じ基点のまま次の通過点を待つ(放射状に何本でも引ける)。
  通過点が基点と同じなら拒否して待ち続ける。
- `Esc` の 1 回目で基点を捨てて基点待ちへ戻り、2 回目で選択ツールへ戻る。
- 通過点には数値入力・直交・極トラッキング・スナップが効く。基点は自分のスナップ候補にしない。
- 保存するのは基点と単位方向。画面では表示範囲で切って描き、基点には線に直交する短い印を画面だけに描く。
- 「構築線」という名前のレイヤーがあればそこへ置く(4.3 節)。
- **使える操作**: 移動・回転・ミラー・複製。トリム・延長の**境界**にできる。交点・近接点・垂線スナップの対象。
- **使えない操作**: トリム・延長・フィレット・面取り・分割・結合・分解の対象にはならない。拘束の対象にもならない。
- **オフセット**: 選んだ構築線を `O` でオフセットすると、平行な位置のクリック点を挟む最も近い交点どうしを結ぶ
  **線分**を、カレントレイヤーへ作る(元の構築線は残る)。交点の相手は他の構築線と表示中の図形。片側に交点が
  無ければ、その端は用紙の縁まで。両側とも決まらないとき・交点の上をクリックしたときは取り消す
  (`Offset: no intersection or paper edge on one side - cancelled`・`Offset: the click is on an intersection - click between two`)。
- **選択**: 矩形選択では基点が枠に入れば選ぶ。ズームフィットは基点だけを範囲に含める。
- **まとめて削除**: 右パネルのレイヤー欄の下の「構築線を全て削除」は、文書中の構築線をすべて削除する
  (非表示のレイヤーの分も含む。ロック中のレイヤーの分は残す)。undo 1 回で戻る。
- 出力(SVG/PDF)では用紙の範囲で切った線分として描く(10 章)。DXF は `XLINE` で往復する(12 章)。

### 5.6 アイソメ円と等測グリッド

- `F5` でグリッドを矩形/等測に切り替える(既定は矩形。`config.json` に保存)。等測グリッドは 30°・90°・150° の
  3 つの線群で描き、グリッドスナップと直交モードも等測の格子・軸に従う。
- アイソメ円(`I`): 中心 → 半径の点(距離 `d`)の 2 クリックで、四心法の 4 本の円弧を作る(undo 1 回)。
  面は上部パネル `Iso face:` か作図中の `Tab` で `Top`(既定)/`Left`/`Right` を循環する。大円弧の半径は
  `(√3/2)d`、小円弧は `(√3/6)d`。縮み率は掛けない。半径 0 は拒否する。Z 軸・真の楕円は持たない。

### 5.7 選択

選択ツール(`S`)で行う。

- **クリック**: カーソルから画面 6 px 以内で最も近い図形を選択集合へ**足す**。空の場所のクリックは何もしない。
- **`Shift`+クリック**: 図形なら選択集合から外す。空の場所なら選択を全部解除する。
- **ドラッグ**: 矩形選択。外接矩形が矩形に**完全に含まれる**エンティティを新しい選択集合にする(足すのではなく
  置き換える)。左右のドラッグ方向で意味は変わらない(窓/交差の区別は無い)。文字・表は紙 mm を `k` 倍した
  大きさで判定する。構築線は基点で判定する。
- **`Esc`**: 矩形ドラッグ中ならドラッグだけを捨てる。そうでなければ選択を全部解除する。
- 表示中のレイヤーのエンティティだけが対象。ロック中のレイヤーのエンティティも選べる。
- 選択中のエンティティは強調色で描く。拘束記号のクリックで拘束を選べる(8.5 節)。
- **削除**: `Delete` / `Backspace` で選択集合を削除する(undo 1 回)。

### 5.8 移動・複製・回転・ミラー

いずれも選択ツールで選択集合を作ってからキーを押す。選択が空なら `Select entities to move` 等を出して何もしない。
クリックにはスナップが効く(直交・極トラッキングは効かない)。配置中はプレビューを出し、`Esc` で取り消す。
結果は undo 1 回で戻る。

| 操作 | キー | 手順 | 規則 |
|---|---|---|---|
| 移動 | `M` | 基準点 → 移動先 | 数値入力可。変位 0 は取り消し |
| 複製 | `Ctrl+D` | 基準点 → 配置先 | 数値入力可。複製は元と同じレイヤー・スタイル。拘束は複製しない。部品欄を含む選択は拒否(`Cannot duplicate: selection includes the bill of materials`) |
| 回転 | `R` | 回転中心 → 基準点 → 回転先 | 角度は「中心→基準点」から「中心→回転先」への相対角。基準点か回転先が中心と同じ、または角度 0 なら取り消し |
| ミラー | `Shift+M` | 軸の 1 点目 → 2 点目 → モーダル「Mirror」 | 「Keep the original entities?」に「Keep original」(元を残し鏡像を新しく足す。拘束は複製しない)/「Delete original」(元を鏡像へ置き換える。拘束も鏡映する)/「Cancel」。軸の長さ 0 は取り消し。部品欄を含む選択で「Keep original」は拒否 |

- 文字は回転で `angle` が変わる。ミラーでは基準点を写し、角度を軸に対して反射する(軸の角度 α に対し `2α − angle`)。字形は裏返さない。
- 表は移動・複製だけを受け、回転・ミラーでは左下の `anchor` だけを写す(表自体は回転も鏡像化もしない)。
- 寸法は定義点を写す。長さ寸法の向き(回転寸法の角度)も回転・ミラーで写す。

### 5.9 修正系の演算

| 操作 | キー | 手順 | 対象・規則 |
|---|---|---|---|
| オフセット | `O`(選択ツールで 1 つ選んでから) | 通過点をクリック、または上部パネル `Offset dist:` に距離を入れて側をクリック | 対象は線分・円・円弧・ポリライン・構築線(構築線は 5.5 節)。選択がちょうど 1 つでなければ拒否(`Select exactly one entity to offset`)。距離欄が空なら通過点方式。ポリラインの角はマイター、マイター長が距離の 4 倍を超える角はベベル。内側へのオフセットで半径が無くなる・距離 0 は取り消し |
| トリム | `X` | 境界 → 対象 | 対象の、クリックした側の部分を除く。対象は線分・円弧(円・ポリラインは不可)。境界は点以外の図形と構築線。交点が複数あればクリック位置に最も近い交点の間を除く(2 断片が残ることがある)。同じ境界のまま続けて対象をクリックできる |
| 延長 | `E` | 境界 → 対象 | 対象の、クリックに近い端を境界まで伸ばす。対象は線分・円弧。境界は点以外の図形と構築線。届かない方向・円弧がほぼ一周を超える延長は拒否 |
| フィレット | `F` | 上部パネル `Fillet radius:` に半径 → 1 本目 → 2 本目 | 線分どうしだけ。各線分の「残したい側」をクリックする。2 本を接点まで切り詰め/延長し、円弧を足す(undo 1 回)。平行・半径が大きすぎる・角の上のクリックは拒否。半径は正の数 |
| 面取り | `Shift+F` | 上部パネル `Dist 1:`・`Dist 2:` → 1 本目 → 2 本目 | 線分どうしだけ。`Dist 2` が空なら `Dist 1` と同じ(等距離)。切り詰めた 2 本の端を結ぶ線分を足す |
| 分割 | `B` | 対象をクリック | クリック点(スナップは 5.3 節)で 2 つの別のエンティティに割る。対象は線分・円弧・開いたポリライン。端点に近すぎる点は拒否 |
| 結合 | `J`(選択ツール) | — | 選択中の線分・開いたポリラインが端点どうしで 1 本の鎖になるときだけ 1 本のポリラインにする(輪になれば閉じる)。2 つ以上の選択が要る。分岐・離れた図形・円弧などを含む選択、レイヤーかスタイルが混ざる選択、長さ 0 の部分を含む選択は拒否 |
| 分解 | `Shift+J`(選択ツール) | — | 選択中のポリラインを辺ごとの線分に分ける(閉じ辺も含む。レイヤー・スタイルは引き継ぐ)。ポリライン以外の選択は残す |

- トリム・延長・フィレット・面取り・分割の対象は、クリック位置に当たる図形をピックする(スナップしない)。
- 拘束のある図形に対する扱いは 8.4 節。

### 5.10 グリップ編集

選択ツールで選んだエンティティにグリップ(小さな四角)を出し、ドラッグで編集する。ドラッグ中はプレビューを出し、
離した時点で確定する(undo 1 回)。ドラッグ先にはスナップが効く。

- **図形のグリップ**: 線分の両端、円・円弧の中心、半径(円は四半円点 4 か所、円弧は掃引の中央 1 か所)、
  円弧の両端。各グリップは自分の値だけを変える(端点を動かせば他方の端は残る)。
  - 拘束のある図形は、拘束に従って追従する図形も含めてプレビューする。解けない位置では直前の解けた形を描いて
    理由を出し、そこで離すと図面は変わらない。プレビューの演算量の予算を超えた位置では掴んだ図形だけを描き、
    離すと確定を試みる(8.6 節)。
  - ロック中のレイヤーの図形、固定拘束の付いた図形、選択が 100 個を超えるときはグリップを出さない。
- **寸法のグリップ**: 6.9 節。寸法の文字のドラッグも 6.9 節。
- グリップの当たり判定は画面 8 px。重なったときの優先順位は 寸法のグリップ > 拘束記号 > 図形のピック。

## 6. 寸法

### 6.1 共通の規則

- 寸法は 5 種類(長さ・半径・直径・角度・座標)。どれも「寸法線」レイヤーがあればそこへ置く(4.3 節)。
- 値は定義点から毎回計算する(保存しない)。寸法は図形と関連付かない(4.5 節)。
- 寸法は常に実線で描き、線幅・色はレイヤー/スタイルに従う。
- 作図中はカーソルに追従するプレビューを出す。クリックにはスナップが効く。数値入力は受けない。
- 退化する入力(計測 2 点が一致・投影長 0・半径 0 など)は理由を出して拒否し、その段階で待ち続ける。
- 寸法の大きさ(文字高さ・矢の長さ・すきま)は文書の寸法スタイル(6.7 節)の紙 mm に `k` を掛けたもの。
  画面で紙基準表示が OFF のときは画面固定の大きさで描く(9.3 節)。出力は常に紙基準。

### 6.2 種類ごとの作図手順

| 種類 | キー | 手順 | 規則 |
|---|---|---|---|
| 長さ | `D` | 計測点 1 → 計測点 2 → 寸法線の位置 | 下記 |
| 半径 | `Shift+D` | 円・円弧をクリック → 引出線の方向 | 中心から円周への半径線。矢先は円周上で外向き |
| 直径 | `G` | 円・円弧をクリック → 寸法線の向き | 中心を通る直径線の両端に矢先。補助線は無い。値は直径 |
| 角度 | `Shift+G` | `3 points`: 頂点 → 1 辺目の点 → 2 辺目の点 → 弧の位置 / `2 lines`: 線 1 → 線 2 → 弧の位置 | 下記 |
| 座標 | `Shift+V` | 原点 → 計測点 → 引出線の端 | 下記 |

**長さ寸法**

- 向き(上部パネル `Dim dir:`、または `Tab` で循環): `Aligned`(整列。計測 2 点を結ぶ向き)/`Horizontal`/`Vertical`。
  水平・鉛直は回転寸法(角度 0°・90°)として保存する。値は寸法線の向きへの投影長。
- 直交モード(`F8`)が ON で向きが整列のときは、計測 2 点の角度に近い軸(水平/鉛直)へ自動で倒れる。
- 上部パネル `Ext angle:`(度。空欄は寸法線に垂直)で補助線の傾きを指定できる。傾けても値は変わらない。
  補助線が寸法線とほぼ平行になる指定では補助線を描かない。不正な文字列のときは確定を拒否する。
- 任意角の向きと、既存の寸法の向き・補助線の傾きの変更は右パネル「寸法」で行う(6.6 節)。
- 連続入力(上部パネル `Dim chain:`。`Tab` では変わらない): `Single`(既定。1 本ごとに 3 クリック)/
  `Series`(直列。前の寸法の計測点 2 を次の計測点 1 として引き継ぎ、寸法線を 1 本目と同一直線上に揃える。
  2 本目以降は計測点 1 クリック)/`Parallel`(並列。1 本目の計測点 1 を固定し、計測点 → 寸法線の位置の 2 クリック)。
  系列の途中で向きか連続モードを変えると系列を捨てて最初から。確定に失敗(レイヤーロック等)しても系列は保つ。

**角度寸法**

- 上部パネル `Angular mode:` か `Tab` で `3 points`/`2 lines` を切り替える。
- `3 points`: 頂点と 2 辺の点を選ぶ。辺の点が頂点と一致・2 辺が同じ向き・反平行(180°)は拒否する。
- `2 lines`: 線分またはポリラインの辺を 2 本選ぶ。2 直線の交点(延長上でもよい)を頂点とし、弧を置いた側の角を
  測る。フィレット・面取りで欠けた角にも付けられる。平行・弧の位置が辺の直線上・線分以外のピックは拒否する。
- 180° を超える角(優角)は扱わない。値は度で、`°` を付ける。弧と、頂点からの補助線で描く。

**座標寸法**

- `Esc` を押すまで原点を保ち、計測点 → 引出線の端の 2 クリックで続けて置ける。
- 軸は上部パネル `Ord axis:` か `Tab` で `Auto`(引出線の向きで X/Y を判定)/`X`/`Y`。
- 値は「計測点 − 原点」のその軸の成分(符号つき。負なら `-30` のように出す)。記号・単位は付かない。矢先は無い。
  引出線は計測点から引出線の端までの直線で、値は引出線の先に置く。引出線の長さ 0 は拒否する。

### 6.3 表示の規則

- **文字の位置**: 長さ・直径寸法は寸法線の中央の**上側**(読み方向の左側。水平な寸法線なら上、垂直な寸法線なら
  左)へ、寸法スタイルの「文字とのすきま」をあけて置く。半径寸法は円周点の少し外側へ水平に置く。角度寸法は弧の
  中央の外側、座標寸法は引出線の先。
- **読み方向**: 文字の向きは寸法線(角度寸法は弧の中央の接線、座標寸法は引出線)を、左下から右上へ読める向き
  (角度が -90° より大きく +90° 以下)へ正規化したもの。`offset` の符号や表示の向きでは変わらない。
- **補助線**: 計測点から「補助線のすきま」をあけて始め、寸法線を「補助線の突き出し」だけ越えて終わる。計測点から
  寸法線までの距離がすきま以下なら補助線を描かない。
- **矢の向き**: 矢の配置が自動なら、ラベルの幅 + 矢先の長さ × 2 が寸法線の長さに収まらないとき外向きにし、寸法線を
  両端へ矢先の長さだけ延ばす。右パネルで内向き・外向きに固定できる。矢先が「斜線」「点」「なし」のときは寸法線に
  沿って場所を取らないので、外向きにならない(配置の指定も効かない)。
- **退化**: 描けない寸法(角度寸法の辺が決まらない等)は値ラベルだけを描き、選択・削除できるようにする。

### 6.4 寸法値の組版

1 つの寸法の文字は左から次の順に並べる。

```
接頭辞 → 寸法補助記号 → 値 → (角度寸法の °) → 接尾辞 → サイズ公差
```

- **値**: 桁数(寸法の上書きがあればそれ、無ければ寸法スタイル)で丸める。末尾ゼロを省く設定なら、末尾の `0` と
  余った小数点を落とす(`120.00` → `120`、`12.50` → `12.5`。桁数 0 のときは落とさない)。
- **寸法補助記号**(種類ごとに付けてよいもの):

  | 寸法 | 付けてよい記号 | 既定(未指定のとき描く記号) |
  |---|---|---|
  | 長さ | `φ` `Sφ` `□` `C` `t` | なし |
  | 半径 | `R` `SR` `CR` | `R` |
  | 直径 | `φ` `Sφ` | `φ` |
  | 角度・座標 | なし | なし |

  `φ` と `□` は線で描く記号、`R` `SR` `CR` `C` `t` と `Sφ` の `S` はフォントの文字。記号を選んでいない半径・直径寸法は
  描くときに `R`・`φ` を補う(データには書かない)。
- **サイズ公差**:
  - 対称: `± v`。値との間に半角 1 文字ぶんあけ、値と同じ高さ。`v` は 0 以上。
  - 上下偏差: 上段に上の許容差、下段に下の許容差を、文字高さ × 公差文字の縮小率で縦に積む。符号を付け
    (`+0.2`・`-0.1`)、丸めて 0 になる値には符号を付けない。上 < 下は拒否する。
  - はめあい記号: 値の直後に同じ高さで書く(`φ20H7`)。表示だけで偏差値へは展開しない。受け付ける形は英字 1〜2
    文字 + 数字 1〜2 桁で、数字は 18 以下(`H7`・`g6`・`js13`)。大小文字は区別する。`H7/g6` のような組み合わせは不可。
- **表記**: 「通常」/「参考寸法 (括弧)」(記号・値・`°`・接尾辞を丸括弧で囲む)/「理論的に正確な寸法 (枠)」(同じ範囲を
  矩形の枠で囲む)。接頭辞と公差は括弧・枠の外。
- **表示値の上書き**(非比例寸法): 値の代わりに任意の文字列を出し、値の部分に下線を引く。表記・記号・公差・`°` は
  上書きした値にも付く。
- **接頭辞・接尾辞**: 各 32 文字まで(例 `2×`、`-M6`)。
- **文字の向き**: 「自動」(上の読み方向)/「水平」/「任意角」(ワールドでの絶対角)。

### 6.5 文字の幅の見積もり

寸法のラベルの幅は、文字ごとの送り幅の和で見積もる(外向き矢の判定・ラベルの外形・文字の下の塗り・DXF の `TEXT`
の位置に使う)。

- ASCII の文字は文字高さ × 0.55。ただし送り幅がそれより広い ASCII 文字(`M`・`W`・`H`・`m` など 38 文字)は、同梱
  フォント(Noto Sans JP)の実測の送り幅を使う。
- ASCII 以外の文字(`×`・`±`・日本語など)は文字高さ × 1.0。
- フォントの文字で描く記号(`R`・`SR`・`CR`・`C`・`t`・`Sφ` の `S`)の送り幅も同じ実測値。値は記号の送り幅のすぐ後ろ
  から始まる。
- この実測値は SVG/PDF の字形(同梱フォント)に対して正確で、画面の英字(GUI の既定フォントで描く)とは少しずれる。
- 文字エンティティの外形の見積もりは別の式(7.1 節)で、この表を使わない。

### 6.6 右パネル「寸法」

寸法を選ぶと右パネルに「寸法」セクションが出る。見出しの下に「選択中: N 件(長さ a・半径 b・直径 c・角度 d・座標 e)」。
複数を選んでいれば、変更は選択中の全寸法へ undo 1 回で適用する。値が混ざっている項目は「(混在)」「混在」と出す。

| 項目 | 内容 |
|---|---|
| 記号: | 選択中の全寸法で付けてよい記号の共通部分から選ぶ。未指定の項目は、全件の既定が同じなら「R(既定)」「φ(既定)」、全件に既定が無ければ「なし」、既定が混ざれば「既定」と出す。半径・直径寸法には「なし」を出さず、既定と同じ記号も並べない(選択中のどれかがその記号を明示していれば出す) |
| 公差: | 「なし」/「± 対称」/「上下偏差」/「はめあい記号」。値は `± :`・`上 :`/`下 :` 等の欄に入れて「確定」 |
| 桁数 | 「スタイルに従う(現在 n 桁)」のチェック。外すと 0〜4 の整数を入れる。スタイルに従う寸法は、後から寸法スタイルを変えると追従する |
| 矢印の配置: | 「自動」/「内向き」/「外向き」。矢先が斜線・点・なしのときは無効 |
| 表示値の上書き: | 文字列を入れて確定。「解除」で戻す |
| 表記: | 「通常」/「参考寸法 (括弧)」/「理論的に正確な寸法 (枠)」 |
| 接頭辞: / 接尾辞: | 確定/解除 |
| 文字位置: | 「自動」/「手動」/「混在」の表示と「自動配置に戻す」 |
| 文字の向き: | 「自動」/「水平」/「任意角」(「角度:」欄、度) |
| 見た目の上書きを一括解除 | 桁数・文字位置・文字の向き・表示値の上書き・矢の配置を戻す。記号・公差・表記・接頭辞/接尾辞は残す |

選択に長さ寸法が 1 件以上あるときは、さらに次を出す(長さ寸法だけに効き、他の種類は無視する)。

| 項目 | 内容 |
|---|---|
| 向き: | 「整列」/「水平」/「鉛直」/「任意角」(角度、度)。向きを変えても寸法線の位置(中点)を保つ。向きが定まらない・投影長が 0 になる寸法を含むと拒否 |
| 補助線の傾き: | 度。空欄で寸法線に垂直 |
| 寸法線の間隔: | 計測点から寸法線までの距離(正の数)。「確定」で選択中の長さ寸法すべてに適用し(undo 1 回)、寸法線が計測点のどちら側にあるかは保つ。欄は小数 3 桁に丸めて表示する |

### 6.7 寸法スタイル

文書に 1 つの寸法スタイルを持ち、全寸法に効く。右パネル「寸法スタイル」の「寸法スタイルを編集…」で開く
ダイアログ「寸法スタイルを編集」で変える(OK で undo 1 回。「既定に戻す」あり。不正な値は理由を出して拒否)。

| ダイアログの項目 | 既定 | 範囲 |
|---|---|---|
| 文字高さ[mm]: | 3.5 | 0 < x ≤ 1000 |
| 矢の長さ[mm]: | 5.0 | 0 < x ≤ 1000 |
| 矢先: | 塗りつぶし矢 | 下表 |
| 小数桁数(0〜4): | 2 | 0〜4 の整数 |
| 末尾ゼロを省く: | ON | — |
| 補助線のすきま[mm]: | 1.0 | 0 ≤ x ≤ 1000 |
| 補助線の突き出し[mm]: | 2.0 | 0 ≤ x ≤ 1000 |
| 文字とのすきま[mm]: | 1.4 | 0 ≤ x ≤ 1000 |
| 公差文字の縮小率: | 0.7 | 0 < x ≤ 1 |

**矢先**(7 種。画面・SVG/PDF で同じ形):

| UI の名前 | ファイルの値 |
|---|---|
| 塗りつぶし矢(既定。全開き 30°) | `ClosedFilled` |
| 白抜き矢 | `ClosedBlank` |
| 開いた矢 30° | `Open30` |
| 開いた矢 90° | `Open90` |
| 斜線 | `Oblique` |
| 点 | `Dot` |
| なし | `None` |

寸法スタイルは `.mcad` に保存する(設定ファイルではない)。v1〜v4 の `.mcad` は寸法スタイルを持たないので、保存当時の
値(矢の長さ 3.0 mm、他は既定と同じ)で読む(11.4 節)。

### 6.8 文字の下の塗りと接続線

- **塗り**: 全種類の寸法で、ラベルの外形を紙 0.5 mm 膨らませた四角形を背景色で塗る。設定は無く常に有効。
- **描画順**: 1 つの寸法の中は (1) 寸法線・補助線・矢先・角度寸法の弧 → (2) 塗り → (3) 文字・φ/□ の記号・下線・
  理論的に正確な寸法の枠・接続線 の順に描く。帰結として、文字の下にある自分の線は消え、下線・枠・接続線は消えない。
- 塗りが消すのは**先に描かれたもの**だけ: 重ね順が下のレイヤーの図形、同じレイヤーで先に描かれた図形(別の寸法の
  線・文字を含む)、図面枠・表題欄、画面のグリッドと用紙縁。重ね順が上のレイヤーの図形と、同じレイヤーで後から
  描かれた図形は消えない。
- 背景色は画面が作図領域の背景色、SVG/PDF が用紙の背景色(青図モードでは紺。10.2 節)。
- 画面で塗るのは文書の通常の描画だけで、選択の強調・ゴースト・作図プレビューには塗りを入れない(このため選択中は
  強調色の線が文字の上に見える)。文字が小さすぎて描かれないときは塗らない。
- **DXF には塗りを出さない**(文字の下の線は他の CAD ではそのまま見える)。
- **接続線**: 長さ・直径・半径・角度寸法で、文字を手で動かし(文字位置が手動)、ラベルの四角形と描画上の寸法線
  (外向き矢で延ばした線、半径は半径線、角度は弧)の最短距離が「文字とのすきま」× 2 より大きいとき、細い線で
  つなぐ。端点はラベル側が 4 辺の中点のうち寸法線に最も近い点、寸法線側はその点からの最近点。保存はせず、毎回
  計算する。画面・SVG/PDF・DXF(`LINE`)に出る。座標寸法には出さない。紙基準表示 OFF の画面ではズームで線の有無が
  変わることがある。

### 6.9 寸法の後編集

- **グリップ**: 選択中の寸法に次のグリップを出し、ドラッグで編集する(スナップが効く。undo 1 回)。

  | 寸法 | グリップ |
  |---|---|
  | 長さ | 計測点 1・計測点 2・寸法線の中点(寸法線の位置だけを動かす) |
  | 角度 | 頂点・辺の点 1・辺の点 2・弧の中央(弧の半径) |
  | 座標 | 計測点・引出線の端 |
  | 半径・直径 | 円周上の点(向きだけを動かす) |

- **文字位置**: 選択中の寸法の文字(枠を表示する)をドラッグすると文字位置が手動になる。ごく小さなドラッグは無視する。
  「自動配置に戻す」で戻す。文字の当たり判定は表示の大きさに依存する(通常の選択の当たり判定は保存データだけで
  決まり、ズームに依存しない)。

## 7. 文字・表・部品欄・表題欄

### 7.1 文字

- `T` を押し、基準点(ベースラインの左端)をクリックするか数値入力で `x,y` を打って `Enter`(相対の書式は基点が
  無いので拒否)。基準点が決まると上部パネルに `Text:`(文字列。日本語入力可)と `H:`(高さ、紙 mm。既定 `3.5`)が
  出る。どちらかの欄で `Enter` を押すと確定する。`Esc` で取り消す。
- 文字列は 1 行。空文字列・正でない高さは拒否する(`Invalid text height - enter a positive number` 等)。
- 作るときの角度は 0。回転は回転操作(5.8 節)で行う。揃えは常に左・ベースライン(中央・右揃えは無い)。
- 「文字」レイヤーがあればそこへ置く。
- 画面・SVG/PDF とも同梱の Noto Sans JP で描く(英字は画面では GUI の既定フォントになる)。文字の外形(選択・矩形
  選択・ズームフィット)は、ASCII 文字を高さ × 0.55、それ以外を高さ × 1.0 として足した幅と、文字高さの箱を
  文字の角度で回したもので近似する(寸法ラベルの見積もり 6.5 節とは別の式)。
- スナップでは基準点だけが端点の候補になる。

### 7.2 表

- `K` で置く(部品欄を作る条件は 7.3 節)。部品欄にならないときは、クリック位置(スナップ可)を左下にして
  **3 行 × 3 列・列幅 30 mm・行高さ 8 mm・文字高さ 3.5 mm** の空の表を置く。続けてクリックすれば何個でも置ける。
- **データ**: 左下の位置 `anchor`(ワールド)、列幅・行高さ・文字高さ(紙 mm)、列ごとの水平の揃え(左/中央/右)、
  セルの文字列(行優先。行 0 が最上段)、種類(表/部品欄)。
- **制約**: 行・列は 1 以上で、行は 512 まで・列は 64 まで。列幅・行高さ・文字高さと幅・高さの合計は有限・正・
  10,000 mm 以下。文字高さは最も低い行の高さ未満。セル数 = 行 × 列。セルに制御文字は不可。揃えの数 = 列数。
- **描画**: 外枠 0.5 mm、内部の罫線 0.13 mm。セルの文字は揃えに従って置き(左揃えは左端から 1.5 mm)、垂直は
  おおよそ中央。画面・SVG/PDF・DXF が同じ配置を使い、紙基準表示を切り替えても罫線と文字の関係は変わらない。
- 表は回転・鏡像化しない(5.8 節)。スナップの候補を出さない。「文字」レイヤーがあればそこへ置く。
- **右パネル「表」**: 表を 1 つだけ選ぶと出る(複数なら「表を1つだけ選択してください」)。表なら「表: R 行 × C 列」と
  「表を編集…」、部品欄なら「部品欄: 部品 n 行」と「記入…」「部品欄の設定…」、注記「部品欄への記入は手動です
  （自動集計は行いません）。」。
- **ダイアログ「表を編集」**(サイズ変更可): セルのグリッド、列ごとの「列幅[mm]」「揃え」(左揃え/中央揃え/右揃え)、
  「行高さ[mm](全行共通):」「文字高さ[mm]:」。行・列の見出しをクリックして選び、「行:」の「上に挿入」「下に挿入」
  「行を削除」、「列:」の「左に挿入」「右に挿入」「列を削除」(新しい列の幅は 30 mm)。不正な値のときは OK を押せず
  理由(「入力に誤りがあります」等)を出す。OK で undo 1 回。キャンセルで何も変えない。

### 7.3 部品欄

- 部品欄は種類が「部品欄」の表で、**1 図面に 1 つまで**。2 つ目を作る操作(追加・複製・種類の変更・それを含む
  一括操作)は拒否する。手で編集して部品欄を 2 つ持たせた `.mcad` は読み込めない。
- **「部品欄を使う」**(右パネル「図面」のチェック。図面ごと、既定 ON): ON で図面にまだ部品欄が無いとき、`K` は部品欄を
  作る。図面枠が表示されていれば、`K` を押した瞬間に表題欄の直上へ置いて選択する(「部品欄を配置しました」)。表示されて
  いなければクリック位置へ置く。OFF にしても既存の部品欄は消えず、表示・出力も変わらない(`K` が部品欄を作らないだけ)。
  OFF のとき、または既に部品欄があるときは、`K` は通常の表を置く。
- **プリセット**(見出し行は最下段で、部品の行は上へ積む。行高さ 8 mm・文字高さ 3.5 mm。新しく作ると見出し + 空の部品行 3 行):

  | 表題欄の様式 | 幅 | 列(列幅 mm) |
  |---|---|---|
  | A・C | 170 | 部番 10・品番 35・名称 35・個数 10・材質 30・質量[kg] 20・備考 30 |
  | B | 120 | 部番 10・品番 25・名称 25・個数 10・材質 30・質量[kg] 20 |
  | ユーザー定義 | 表題欄の幅 | A・C の 7 列を表題欄の幅に比例して配分 |

  揃えは 部番・個数・材質・質量[kg] が中央、品番・名称・備考が左。部番は照合番号(図中の風船の番号)、品番は品目番号、
  質量は 1 個あたりの値。
- **表題欄の直上**: 部品欄の左下を表題欄の左上に合わせる(幅が表題欄と同じなので右端もそろう)。
- **追従**: 部品欄が表題欄の直上にある(紙 1e-6 mm 以内)状態で、表題欄の位置が変わる図面の変更(用紙・向き・様式・
  尺度)をすると、部品欄も新しい表題欄の直上へ動く(図面の変更と同じ undo 1 回)。図面枠が無効・部品欄のレイヤーが
  ロック中のときは動かさず理由を出す。ほかの場所へ動かした部品欄は追従しない。列構成は変えない。
- **ダイアログ「部品欄に記入」**(「記入…」): セルの記入と部品の行の追加・削除だけ。見出し行は消せず、その下へは
  挿入できない。
- **ダイアログ「部品欄の設定」**(「部品欄の設定…」): 列(列名・列幅・揃え)・行高さ・文字高さ。「表題欄の上に配置」
  (編集内容を反映し、表題欄の直上へ移して閉じる。図面枠が無効なら不可)、「様式に合わせ直す」(ダイアログでの編集は
  捨て、列構成・列幅・揃え・行高さ・文字高さを表題欄の様式の既定へ戻して閉じる)。
- 記入は手で行う。図形からの自動集計は無い。
- v0.11.1 以前の図面の部品表は通常の表として読む(中身から部品欄を推測しない。11.4 節)。必要なら `K` で作り直す。

### 7.4 表題欄の記入

右パネル「図面」の「表題欄を編集…」で開くダイアログ「表題欄を編集」に、「図面番号:」「図面名称:」「投影法:」
(「第三角法」/「第一角法」)「作成者:」「作成日:」「改訂記号:」を入れる。OK で undo 1 回。作成日は書式を問わない
文字列。尺度・用紙の欄は自動(3.5 節)。

## 8. 幾何拘束

### 8.1 対象と種類

- 拘束を付けられるのは**線分・円・円弧**だけ。ポリライン・点・構築線・文字・寸法・表は対象外(ポリラインは
  分解すれば使える)。
- 点を指す拘束は、図形の「始点」(`Start`)・「終点」(`End`)・「中心」(`Center`)を指す。円は中心だけ、線分は
  始点・終点、円弧は 3 つすべてを持つ。
- 種類(上部パネルのコンボの名前 / 右パネルの名前 / 選ぶ対象):

  | コンボ | 右パネル | 対象 | 値 |
  |---|---|---|---|
  | `Coincident` | 一致 | 点 2 つ | — |
  | `Horizontal` | 水平 | 線分 1 本 | — |
  | `Vertical` | 垂直 | 線分 1 本 | — |
  | `Distance` | 距離 | 点 2 つ | 距離 mm |
  | `Point-line distance` | 点と線の距離 | 点 1 つ・線分 1 本 | 距離 mm(点が線のどちら側にあるかも保存) |
  | `Parallel` | 平行 | 線分 2 本 | — |
  | `Perpendicular` | 直交 | 線分 2 本 | — |
  | `Equal length` | 等長 | 線分 2 本 | — |
  | `Equal radius` | 等半径 | 円・円弧 2 つ | — |
  | `Radius` | 半径 | 円・円弧 1 つ | 半径 mm |
  | `Angle` | 角度 | 線分 2 本 | 1 本目から 2 本目への CCW の角度(度。符号は今の形に合わせる) |
  | `Tangent` | 接線 | 線分と円・円弧、または円・円弧 2 つ | 線と円: 円が線のどちら側か。円どうし: 外接か内接か(内接ならどちらが大きいか) |
  | `Fix point` | 点の固定 | 点 1 つ | 固定する位置(今の位置) |
  | `Fix entity` | 図形の固定 | 図形 1 つ | — |

- 線は**無限直線**として扱う(接点や足が線分の外、延長上にあってもよい)。円弧も台の円として扱う。
- 拘束は寸法と別のもので、寸法の値を変えても形は動かない(駆動寸法は無い)。

### 8.2 付け方(拘束ツール `Q`)

- 上部パネル `Constraint:` のコンボで種類を選び、案内(`click an endpoint or a center`・`click a line`・
  `click a circle or an arc` 等)に従って端点・中心や図形をクリックする。最後の対象をクリックした時点で 1 件を足す
  (undo 1 回)。種類は `Tab` では変わらない。
- **先に選んだ図形は止まり、後に選んだ図形が動く**。先に選んだ図形を止めたままでは満たせないときだけ両方を動かす。
- 距離・点と線の距離・半径・角度は、上部パネル `Value:`(mm または deg)で値を指定できる。空欄なら今の形の値で付ける。
- 水平・垂直・平行・直交・角度を付けて線分の長さが変わったときは、成功の通知に
  `a line changed length (add a Distance constraint to keep it)` を添える。
- 成功は `Added {種類} constraint`、失敗は `Constraint failed: {理由}`。
- `Esc` の 1 回目で選んだ対象を捨て、2 回目でツールを終える。ツールを切り替えても選んだ対象は捨てる(種類は保つ)。
- 満たせない(矛盾する)拘束は付けない。矛盾しない重複(水平の線分に平行な線分へさらに水平)は受け付ける。

### 8.3 解き方の約束

- **拘束は常に満たされている**: 図面を変える操作のたびに、変わった図形を含む拘束のつながり(連結成分)を解き、
  追従した図形の変更を**同じ undo 単位**に入れる。複数の変更からなる操作は、全部を適用してから 1 回だけ解く
  (変更の順序で結果が変わらない)。
- 解くときに**止めておくもの**: (a) 図形の固定の対象、(b) ロック中のレイヤーの図形、(c) その操作で利用者が
  変えた値(動かした図形・ドラッグしたグリップの値)。それ以外の値を、変化が最小になるように動かす。
- 帰結として、利用者が動かした図形そのものが拘束に反すれば**拒否**する(水平拘束の線分を回す、固定した図形を
  動かす等)。黙って拘束を外す・形を戻すことはしない。
- 解けないとき(解が無い・動かせる値が無い・解いた形が退化する・演算量の予算を超える)は操作全体を取り消し、図面は
  そのまま。理由をステータスバーへ出す(`no shape satisfies the constraints …`・`entity is fixed by a constraint: …`・
  `the connected constraints are too large to solve within the work budget` 等)。
- 退化とみなす形: 線分の長さ・半径が 0 に近い、円弧の掃引角が 0 か 2π を超える、内接の 2 円の半径差が 0 に近い。
- 拘束が 1 件も無い図面では解かない(拘束を使わない図面の動作・性能は拘束が無い版と同じ)。
- 値の変更(右パネル)は止めるものを足さずに解く。
- 読込時は解かない(11.3 節)。

### 8.4 編集操作と拘束

| 操作 | 拘束の扱い |
|---|---|
| 移動・回転・ミラー(元を置き換え)・グリップ | 残して解き直す。ミラーは拘束も鏡映する(側・角度の符号を写す) |
| トリム(1 断片が残る)・延長 | 位置の変わった点を指す一致・距離と、端点が動いた線分の等長を消す。向き・直線・半径に依存する拘束(水平・垂直・平行・直交・角度・点と線の距離・接線・半径・等半径)は残す。図形の固定、または動いた点の固定がある図形は拒否 |
| フィレット・面取り | 2 本の線分は上と同じ規則(角の一致は消える)。新しい円弧・線分に拘束は付けない |
| トリム(2 断片)・分割 | 元の図形の拘束をすべて消す(新しい断片へは移さない) |
| 結合 | 各線分の拘束をすべて消す |
| 削除 | その図形を指す拘束をすべて消す |
| 複製・ミラー(元を残す) | 拘束は複製しない |

- 消えた拘束は同じ undo 単位に入り、undo で図形と一緒に戻る。消した件数は成功の通知の末尾に
  `, removed n constraint(s)` と添える。
- 拘束のある線分・円・円弧の切り詰め・延長は、元の直線・円を変えない変更だけを受ける(それ以外は拒否)。

### 8.5 表示と右パネル「拘束」

- **拘束記号**: `H`(水平)・`V`(垂直)・`∥`(平行)・`⊥`(直交)・`=`(等長・等半径)・`T`(接線)・錠前(固定)・一致の
  丸印・値つきの距離/半径/角度を、画面固定の大きさで図形の近くに描く。接点が延長上にある接線は、端点まで破線で
  つなぐ。**記号は画面だけで、SVG/PDF・DXF には出さない**。右パネル「拘束」の「拘束記号を表示」(既定 ON、
  `config.json` に保存)で隠せる。
- 記号をクリックするとその拘束を選び、`Delete` でその拘束だけを消す(undo 1 回。通知 `Removed constraint`)。
- **右パネル「拘束」**: 線分・円・円弧を選ぶと、それに付いた拘束の一覧(種類名・値の編集・接点などが延長上なら
  「(延長上)」・「削除」)を出す。行にマウスを乗せると対象の図形と記号を強調する。値の編集と削除は undo 1 回。
  対象を選んでいないときは「拘束の対象になる図形を選ぶと表示します」、拘束が無ければ「この図形に付いた拘束は
  ありません」。
- **自由度**: 選んだ図形を含む連結成分ごとに「成分 n(図形 m 個): 自由度 d」と出す。計算が予算を超える成分は
  「自由度: 大きすぎるため計算していません」。

### 8.6 演算量の予算

求解は実時間ではなく演算回数で打ち切る(機械の速さで結果が変わらないように)。目安の時間は開発環境での実測に
基づく目標値で、上限の保証ではない。

| 場面 | 予算(演算の単位数) | 目安 |
|---|---|---|
| 操作の確定 | 1,200,000,000 | 約 2 秒 |
| グリップのドラッグ中のプレビュー(1 フレーム) | 9,400,000 | 約 16 ms |
| 右パネルの自由度の計算 | 74,000,000 | 約 200 ms |

- 既に満たされた拘束は予算を使わない(大きな図面も開ける)。
- 確定で予算を超えると `the connected constraints are too large to solve within the work budget` で拒否する。
- プレビューで予算を超えた位置では掴んだ図形だけを描き、離すと確定の予算で解く。

## 9. 表示と操作

### 9.1 画面の構成

- **上部パネル 1 行目**(左から): `File: {ファイル名}{*}` / `Recent` メニュー / `Tool: {ツール名}` /
  `Cursor: {x}, {y}`(カーソルのワールド座標、スナップ前、小数 2 桁。キャンバス外は `Cursor: -`) / `Snap: ON|OFF` /
  `Snap types` メニュー / `Ortho: ON|OFF` / `Polar: ON (15°)` または `Polar: OFF` と刻み角のコンボ /
  `Paper view: ON|OFF` / `Grid: {間隔} mm` / ツールごとの入力欄 / ステータスバーの通知。
  - ツールごとの入力欄: `Offset dist:`(オフセット中)、`Fillet radius:`、`Dist 1:`・`Dist 2:`、`Sides:`、
    `Constraint:`・`Value:`・案内、`Iso face:`/`Polygon mode:`/`Dim dir:`/`Angular mode:`/`Ord axis:` のコンボと `(Tab)`、
    `Dim chain:`、`Ext angle:`、`Text:`・`H:`。
- **上部パネル 2 行目**: キーの凡例。幅に応じて折り返す。凡例に載るのは `S=Select` `1=Point` `L=Line`
  `Shift+L=Construction Line` `C=Circle` `Shift+C=Polygon` `A=Arc` `I=Iso Circle` `P=Polyline` `Shift+P=Rectangle`
  `T=Text` `K=Table` `D=Linear Dim` `Shift+D=Radial Dim` `G=Diameter Dim` `X=Trim` `E=Extend` `F=Fillet`
  `Shift+F=Chamfer` `B=Split` `M=Move` `R=Rotate` `Shift+M=Mirror` `O=Offset` `J=Join` `Shift+J=Explode`
  `Ctrl+D=Duplicate` `Del=Delete` `Esc=Cancel` `0-9 . - @=Numeric input` `F3=Snap` `F5=Iso Grid` `F8=Ortho`
  `F9=Paper View` `F10=Polar` `Ctrl+Z=Undo` `Ctrl+Y=Redo` `Ctrl+N=New` `Ctrl+O=Open` `Ctrl+S=Save`
  `Ctrl+Shift+S=Save As` `Ctrl+Shift+O=Import DXF` `Ctrl+E=Export DXF` `Ctrl+Shift+E=Export SVG` `Ctrl+P=Export PDF`
  `Home=Zoom Fit`。`Shift+G`・`Shift+V`・`Q` とマウス操作は凡例に無い(付録 A)。
- **右パネル**(上から): 「レイヤー」・「構築線を全て削除」・「選択中のスタイル」・「寸法」・(長さ寸法の項目)・「表」・
  「拘束」・「図面」・「寸法スタイル」。選択に応じて出るセクションがある。
- **右パネル「図面」**: 「用紙:」(A0〜A4)・「向き:」(横/縦)・「様式:」(A/B/C、ユーザー定義の図面では「ユーザー定義」)・
  「図面枠を表示」・「表題欄を編集…」・「部品欄を使う」・「尺度:」(3.2 節)・「出力色:」(10.2 節)。図面の項目の変更は
  undo 1 回。出力色は図面ではなく設定(undo の対象外)。
- **UI の言語**: 右パネル全体と、ダイアログ「表題欄を編集」「寸法スタイルを編集」「表を編集」「部品欄に記入」
  「部品欄の設定」は日本語。上部パネル・ステータスバーの通知・確認モーダル(「Unsaved changes」「Mirror」)は英語。
  1 つのパネル・ダイアログの中で両者を混ぜない。ファイルダイアログのタイトルは「MCAD開く」「MCAD保存」
  「DXFインポート」「DXF保存」「SVG保存」「PDF保存」。
- フォント: 同梱の Noto Sans JP を GUI 既定フォントの後ろの代替として登録し、文字ごとに代替する(英数字は既定
  フォント、日本語は Noto Sans JP)。

### 9.2 ズーム・パン・グリッド

- **ズーム**: ホイールでカーソルを中心に拡大・縮小する。`Alt` を押しながらマウスを左右に動かすと、動かし始めた
  位置を中心にズームする(右で拡大、左で縮小。往復すると元へ戻る)。
- **パン**: 中ボタンのドラッグ、`Space`+左ドラッグ、`Shift+Alt`+マウス移動。ジェスチャ中に `Shift` を切り替えると
  ズームとパンが入れ替わる。マウスのボタンを押している間の `Alt` 操作は効かない。
- **ズームフィット**: `Home` で図面全体が収まるようにする(構築線は基点だけを含める)。ファイルを開いた直後も同じ。
  空の図面では既定の表示へ戻す。
- **グリッド**: ズームに合わせて 1・2・5 系列の間隔を選び、画面でおよそ 48 px ごとに描く。間隔は `Grid: … mm` に出す。
  `F5` で等測グリッド(5.6 節)。グリッドは出力しない。
- 画面の要素の大きさ: ピック 6 px、スナップ 12 px、グリップ 8 px。

### 9.3 紙基準表示(`F9`)

- ON: 線幅を `線幅[紙 mm] × k × ズーム` px で描く(1 px 未満は 1 px)。寸法の文字・矢先は寸法スタイルの紙 mm で描く
  (出力と同じ見た目)。
- OFF(既定): 線幅は常に 1 px。寸法の矢先は画面 12 px、文字は画面 14 px の固定の大きさで描く。
- 文字エンティティと表は ON/OFF にかかわらず紙 mm × `k` の大きさで描く。線種のダッシュの長さも常に紙 mm 基準
  (1 周期が画面 2 px 未満になると実線で描く)。
- 出力(SVG/PDF)は常に紙基準で、このトグルの影響を受けない。

### 9.4 ファイル操作と確認

| キー | 操作 | 通知(成功/失敗) |
|---|---|---|
| `Ctrl+N` | 新規(4.3 節の図面) | — |
| `Ctrl+O` | `.mcad` を開く | `Opened file` / `Open failed: {理由}` |
| `Ctrl+S` | 保存(ファイル名が無ければ名前を付けて保存) | `Saved` / `Save failed: {理由}` |
| `Ctrl+Shift+S` | 名前を付けて保存(既定のファイル名 `Untitled.mcad`) | 同上 |
| `Ctrl+Shift+O` | DXF を取り込む | 12.4 節 |
| `Ctrl+E` | DXF へ書き出す(`Untitled.dxf`) | 12.3 節 |
| `Ctrl+Shift+E` | SVG へ書き出す(`Untitled.svg`) | 10 章 |
| `Ctrl+P` | PDF へ書き出す(`Untitled.pdf`) | 10 章 |

- 未保存の変更があるときに新規・開く・DXF の取込・`Recent` から開く・ウィンドウを閉じる操作をすると、モーダル
  「Unsaved changes」で確かめる(`Discard unsaved changes and quit?` 等。「Discard and quit」/「Discard and continue」/
  「Cancel」)。
- DXF を取り込んだ図面は常に未保存扱いで、ファイル名を持たない(`Ctrl+S` は `.mcad` での保存になる)。元の DXF を
  上書きしない。
- `Recent` メニューは最近開いた・保存した `.mcad` を最大 5 件、新しい順に出す(存在しないファイルは出さない。無ければ
  `(no recent files)`)。DXF の取込は載せない。
- ファイルダイアログはセッション内で最後に使ったディレクトリを開く(開く・保存・DXF の取込/書出で共有)。

## 10. 出力(SVG/PDF)

### 10.1 共通

- `Ctrl+Shift+E` で SVG、`Ctrl+P` で PDF へ書き出す。どちらも同じ中間表現から作り、見た目は同じ。
- **実寸**: 1 ページ = 用紙 1 枚(向きを反映した大きさ、mm)。ワールド座標を `k` で割った紙 mm で描く(用紙の左下が
  ワールドの原点)。
- **含めるもの**: 表示中のレイヤーのエンティティ(ロック中のレイヤーも含む)、寸法(塗り・接続線を含む)、表、
  図面枠を表示しているときは図面枠と表題欄。描く順は画面と同じ(4.5 節)。
- **含めないもの**: グリッド・用紙縁・スナップマーカー・選択の強調・作図プレビュー・拘束記号・構築線の基点の印。
- 用紙の外にはみ出した図形も切らずにそのまま書く(はみ出しは作図者の責任)。**例外は構築線**で、用紙の範囲で切った
  線分として書き、用紙と交わらなければ出さない(出したくなければレイヤーを非表示にする)。
- **文字**は同梱フォント(Noto Sans JP)の字形をアウトライン(塗りのパス)にして書く。フォントは埋め込まない。
- **線幅**は紙 mm のまま(画面の 1 px 下限は掛けない)。**線種**は紙 mm のダッシュパターン(4.4 節)を、出力形式の
  破線の機能で書く(位相はパスの先頭から)。
- 円・円弧は 3 次ベジエ曲線で書く。
- 紙基準表示(`F9`)は出力に影響しない。

### 10.2 色モード

右パネル「図面」の「出力色:」で選ぶ(`config.json` に保存。画面表示と図面データには影響しない)。

| UI の名前 | 値 | 線・枠の色 | 用紙の背景 |
|---|---|---|---|
| 黒(モノクロ)(既定) | `Monochrome` | すべて黒 | 白 |
| 青図(白線) | `Blueprint` | すべて白 | 紺 `#003153` |
| 元の色 | `Color` | エンティティの色(純白だけ黒に置き換える) | 白 |

- 寸法の文字の下の塗り(6.8 節)は背景色で塗る。PDF では白い用紙の全面の塗りは省くが、文字の下の塗りは常に書く。

## 11. `.mcad` 形式

### 11.1 全体

- 拡張子 `.mcad`。中身は UTF-8 の JSON オブジェクト 1 つ。書き出しは字下げ付きの整形で、常に**現行の版 9** で書く。
- 図面の内容(4.1 節)だけを書き、undo の履歴・選択・表示状態は書かない。削除済みのエンティティ・レイヤーは書かない。
- エンティティ・レイヤーを指すときは ID ではなく**配列の添字**で指す(エンティティの所属レイヤーは `layers` の添字、
  拘束の対象は `entities` の添字)。
- 浮動小数は JSON の数値で書く。NaN・無限大は JSON で表せないので、そのようなファイルは構文エラーになる。
- 角度はすべて**ラジアン**(CCW)。長さはワールドの mm、ただし 3.3 節の量は紙 mm。

**トップレベル(版 9)**

| キー | 型 | 必須 | 内容 |
|---|---|---|---|
| `version` | 整数 | 必須 | `9` |
| `sheet` | オブジェクト | 必須 | 図面メタデータ(11.2 節) |
| `layers` | 配列 | 必須 | レイヤー。**先頭(添字 0)が既定レイヤー**。配列の並びは重ね順ではない(重ね順は `order`) |
| `current_layer` | 整数 | 必須 | カレントレイヤーの添字 |
| `entities` | 配列 | 必須 | エンティティ。並びは追加順(=同じレイヤー内の描画順) |
| `dim_style` | オブジェクト | 任意 | 寸法スタイル(6.7 節)。無ければ既定値 |
| `constraints` | 配列 | 必須 | 拘束(拘束が無くても空配列を書く) |

### 11.2 値の書き方

**共通の値**

| 値 | JSON |
|---|---|
| 点・ベクトル | `{"x": 数, "y": 数}` |
| 色 | `{"r": 0〜255, "g": …, "b": …}` |
| 線種 | `"Continuous"` / `"Dashed"` / `"DashDot"` / `"DashDotDot"` |
| 線幅 | 数(紙 mm、0.05〜5.0。範囲外は読込エラー) |
| 列挙(値を持たない) | 文字列(`"A4"` など) |
| 列挙(値を持つ) | 1 つのキーを持つオブジェクト(`{"Rotated": 0.0}`、`{"Custom": {...}}`) |

**レイヤー** `{"name", "color", "linetype", "width_mm", "visible", "locked", "order"}`(すべて書く)。

**エンティティ** `{"layer": 添字, "style": {"color": 色|null, "width_mm": 数|null, "linetype": 線種|null}, "geom": 幾何}`。
`null` は ByLayer。

**幾何**(`geom`。1 つのキーを持つオブジェクト):

| 種類 | JSON |
|---|---|
| 点 | `{"Shape": {"Point": {"x", "y"}}}` |
| 線分 | `{"Shape": {"Line": {"a": 点, "b": 点}}}` |
| 円 | `{"Shape": {"Circle": {"center": 点, "radius": 数}}}` |
| 円弧 | `{"Shape": {"Arc": {"center", "radius", "start_angle", "end_angle"}}}` |
| ポリライン | `{"Shape": {"Polyline": {"vertices": [点…], "closed": 真偽}}}` |
| 構築線 | `{"XLine": {"base": 点, "dir": 単位ベクトル}}` |
| 文字 | `{"Text": {"anchor": 点, "content": 文字列, "height": 紙mm, "angle": 角}}` |
| 長さ寸法 | `{"DimLinear": {"p1", "p2", "offset": 数, "direction": "Aligned" \| {"Rotated": 角}, "ext_angle"?: 角, "annotation"?: 注記}}` |
| 半径寸法 | `{"DimRadial": {"center", "radius", "leader_angle", "annotation"?}}` |
| 直径寸法 | `{"DimDiameter": {"center", "radius", "angle", "annotation"?}}` |
| 角度寸法 | `{"DimAngular": {"vertex", "p1", "p2", "arc_radius", "annotation"?}}` |
| 座標寸法 | `{"DimOrdinate": {"origin", "feature", "leader_end", "axis": "X" \| "Y", "annotation"?}}` |
| 表 | `{"Table": {"kind": "Table" \| "Bom", "anchor": 点, "col_widths_mm": [数…], "col_aligns": ["Left" \| "Center" \| "Right"…], "row_heights_mm": [数…], "text_height_mm": 数, "cells": [文字列…]}}` |

- `offset` は寸法線の、計測線(向きの方向)からの符号付きのずれ。
- 構築線の `dir` は単位ベクトルでなければならない(長さが 1 から許容値を超えてずれる・零は読込エラー。正規化しない)。
- `ext_angle` は補助線の傾き(絶対角)。無ければ寸法線に垂直で、その場合はキーを書かない。
- 表の `cells` は行優先で、行 0 が最上段。要素数は行 × 列。部品欄では最下段が見出し行。

**注記**(`annotation`。無注記ならキーごと書かない):

| キー | 値 |
|---|---|
| `symbol` | `null` / `"Diameter"`(φ) / `"SphereDiameter"`(Sφ) / `"Square"`(□) / `"Radius"`(R) / `"SphereRadius"`(SR) / `"ControlRadius"`(CR) / `"Chamfer"`(C) / `"Thickness"`(t) |
| `tolerance` | `null` / `{"Symmetric": 数}` / `{"Deviations": {"upper": 数, "lower": 数}}` / `{"Fit": "H7"}` |
| `decimals_override` | `null`(スタイルに従う) / 0〜4 |
| `text_anchor` | `null`(自動配置) / 点(手で置いた文字の位置) |
| `arrow_placement` | `"Auto"` / `"Inside"` / `"Outside"` |
| `value_override` | `null` / 文字列(非比例寸法) |
| `text_rotation` | `null`(自動) / 角(ワールドの絶対角。水平は `0.0`) |
| `value_style` | `"Plain"` / `"Reference"` / `"TheoreticallyExact"` |
| `prefix` / `suffix` | `null` / 文字列(32 文字まで) |

種類に許されない記号(6.4 節)・上 < 下の公差・非有限の値・不正なはめあい記号・負の対称公差・5 桁以上は読込エラー。

**図面メタデータ**(`sheet`):

```json
{
  "unit": "Millimeter",
  "scale": {"num": 1, "den": 2},
  "paper": "A0" | "A1" | "A2" | "A3" | "A4",
  "orientation": "Landscape" | "Portrait",
  "title_block": "A" | "B" | "C" | {"Custom": {"width_mm": 数, "rows": [{"height_mm": 数, "cells": [{"width_mm": 数, "bind": 項目 | null, "text_height_mm": 数}]}]}},
  "fields": {"drawing_number": "", "drawing_title": "", "projection": "ThirdAngle" | "FirstAngle", "author": "", "date": "", "revision": ""},
  "frame_visible": 真偽,
  "use_bom": 真偽
}
```

- 項目(`bind`)は `"DrawingTitle"` `"DrawingNumber"` `"Scale"` `"Projection"` `"Author"` `"Date"` `"PaperSize"` `"Revision"`。
  `null` は予備欄。ユーザー定義様式は段 32 まで・1 段のセル 32 まで、寸法は有限・正。
- 尺度の各項は 1〜1,000,000(範囲外は読込エラー)。

**寸法スタイル**(`dim_style`): `{"text_height_mm", "arrow_len_mm", "decimals", "trim_trailing_zeros", "ext_gap_mm",
"ext_overshoot_mm", "text_gap_mm", "tolerance_scale", "arrow_kind"}`。`arrow_kind` は 6.7 節の値で、無ければ
`"ClosedFilled"`。範囲は 6.7 節。

**拘束**(`constraints` の要素。1 つのキーを持つオブジェクト。点は `{"entity": 添字, "kind": "Start" | "End" | "Center"}`、
線・円は `entities` の添字):

| 種類 | JSON |
|---|---|
| 一致 | `{"Coincident": {"a": 点, "b": 点}}` |
| 水平・垂直 | `{"Horizontal": {"line": 添字}}`・`{"Vertical": {"line": 添字}}` |
| 距離 | `{"Distance": {"a": 点, "b": 点, "value": mm}}` |
| 点と線の距離 | `{"PointLineDistance": {"point": 点, "line": 添字, "side": "Left" \| "Right", "value": mm}}` |
| 平行・直交・等長 | `{"Parallel": {"a", "b"}}`・`{"Perpendicular": {"a", "b"}}`・`{"EqualLength": {"a", "b"}}` |
| 等半径 | `{"EqualRadius": {"a", "b"}}` |
| 半径 | `{"Radius": {"entity": 添字, "value": mm}}` |
| 角度 | `{"Angle": {"a", "b", "value": ラジアン}}`(a から b への CCW) |
| 線と円の接線 | `{"TangentLineCircle": {"line", "circle", "side": "Left" \| "Right"}}` |
| 円どうしの接線 | `{"TangentCircles": {"a", "b", "kind": "External" \| {"Internal": "First" \| "Second"}}}`(内接は大きい方) |
| 点の固定 | `{"FixPoint": {"point": 点, "at": 点}}` |
| 図形の固定 | `{"FixEntity": {"entity": 添字}}` |

`side` は線分の始点 → 終点の向きに対する側(`Left` は符号付き距離が正)。

### 11.3 読込の手順と拒否する入力

読込は次の順に行う。どこかで失敗すれば図面は開かず、ステータスバーに `Open failed: {理由}` を出す(開いていた図面は
そのまま)。

1. `version` を読む。1〜9 以外は `unsupported format version: {n} (supported: 1..=9)` で拒否する。
2. その版の形として JSON を読む(11.4 節。旧版は現行の形へ 1 段ずつ引き上げる)。
3. 中身を検証する: レイヤーが 1 つ以上・`current_layer` とエンティティの `layer` が範囲内・幾何が妥当(非有限・負の半径・
   空のポリライン・表の制約違反・単位でない構築線の方向など)・図面メタデータ・寸法スタイル・注記が妥当。
4. 文書を組み立てる: 先頭のレイヤーを既定レイヤーに当て、残りのレイヤーを足し、エンティティを足し、ロックを最後に
   適用する。**部品欄が 2 つ以上あれば拒否する**。
5. 拘束を配列の順に足す。添字が範囲外・対象の種類が違う・点の種類がその図形に無い・**保存された形で満たされていない**
   拘束は拒否する。**読込時に拘束を解いて形を変えることはしない**。
6. undo の履歴を空にし、未保存の印を消す。

- v1〜v3 の旧線幅(画面 px)を移すときに上限を超えて丸めた件数は、失敗ではなく読込の結果として数える。

### 11.4 版の履歴と旧版の読み方

| 版 | この版で増えたもの | この版のファイルを読むときに補う値 |
|---|---|---|
| 1 | 図形(点・線分・円・円弧・ポリライン)とレイヤー。`geom` は図形を直接書く | 図形を `{"Shape": …}` として読む。レイヤーの重ね順 = 配列の添字 |
| 2 | 文字・長さ寸法・半径寸法(`geom` が `Shape`/`Text`/`Dim…` の形に) | 重ね順 = 配列の添字 |
| 3 | レイヤーの重ね順 `order` | — |
| 4 | `sheet`(尺度・用紙・表題欄)、レイヤーの線種・線幅、スタイルの線幅を紙 mm の ByLayer へ | v1〜v3: `sheet` = 既定(A4 横・1:1・様式B・枠非表示)。スタイルの旧線幅 `width`(px): `1.0` は ByLayer、それ以外は `0.35 × max(px, 1)` mm(5.0 で頭打ち) |
| 5 | 寸法の注記・直径寸法・`dim_style` | v1〜v4: 注記なし、`dim_style` = 保存当時の値(矢の長さ 3.0 mm、他は既定) |
| 6 | 表(`Table`)・矢先の種類 `arrow_kind` | v1〜v5: `arrow_kind` = `ClosedFilled` |
| 7 | 長さ寸法の向き `direction`・補助線の傾き `ext_angle`、角度寸法・座標寸法、注記の `text_rotation`・`value_style`・`prefix`・`suffix` | v1〜v6: 長さ寸法は整列(`Aligned`)・補助線は垂直、新しい注記の項目は既定 |
| 8 | 表の種類 `kind`・列の揃え `col_aligns`・`sheet.use_bom`、構築線 | v1〜v7: 表はすべて通常の表(中身から部品欄を推測しない)・全列左揃え、「部品欄を使う」は ON |
| 9(現行) | 拘束 `constraints` | v1〜v8: 拘束なし |

**旧版を名乗るファイルの検査**

- 旧版の形は凍結してあり、**その版に無いはずのキー・種類が現れたら拒否する**(黙って無視すると意味が変わるため)。
  例: v5 以前の `Table`、v6 以前の長さ寸法の `direction`・`ext_angle`・角度/座標寸法、v7 以前の表の `kind`・`col_aligns`・
  `sheet.use_bom`・構築線、v8 の `constraints` キー。
- v8 で `kind` と `use_bom` は必須。例外として **`col_aligns` が無い v8**(v8 の初期のビルドが書いた形)は、列数ぶんの
  左揃えで補って読む。`col_aligns` の要素数が列数と違えば拒否する。
- **v9 の知らないキーは無視して読む**(トップレベル・レイヤー・`sheet`・`sheet.fields`・`dim_style`・エンティティ・
  `style`・図形)。手で編集したファイルや、同じ版の範囲での追加に寛容にするため。
- 読んだ旧版のファイルを保存すると版 9 で書く(旧版で書き戻す機能は無い)。

### 11.5 互換性の約束

**約束すること**

- mcad 1.x は、mcad 1.0.0 以降が保存した `.mcad` と、0.x が保存した形式 v1〜v9 のファイルを読み込める。
- 読み込みで図面の内容を失わない。旧版に無い項目は、その版の意味に合う既定値で補う(11.4 節)。

**約束しないこと**

1. 新しい形式のファイルを古い mcad で開くこと。版番号で断り、ステータスバーに
   `Open failed: unsupported format version: …` と出す(開いていた図面は変わらない)。
2. DXF の往復(非対称な経路がある。12 章)。
3. `config.json`(アプリの設定。読めないときは既定値で起動する。13 章)。
4. `.mcad` に保存しないもの(undo/redo の履歴・選択・表示位置・作図ツールの状態)。

### 11.6 形式を変えるときのルール

1.0 以降のすべての変更がこのルールを守る。

1. 形式を変えるときは版番号を上げ、旧版を読む経路(版ごとの読み方)を残す。
2. キーは**足すだけ**にし、消さない・名前を変えない・意味を変えない。足すキーには旧版の意味に合う既定値を付ける。
   既定値で補えない変更は、旧版を読むときに変換する(v7 以前の表、v8 の列の揃えの前例)。
3. 版を上げるたびに、その版の見本を書き出し機能の出力から作り、`crates/mcad-io/tests/fixtures/` に足す。古い見本と
   その読込テストは消さない・期待値を書き換えない。
4. 同じ版の中の知らないキーは無視して読む。拒否するのは、旧版を名乗るファイルに新しい版のキーがある場合など、
   黙って読むと意味が変わる場合に限る(v8 の `constraints` の前例)。

見本と、約束を固定するテストは[付録 B](#b-受け入れテストとの対応)。

## 12. DXF

### 12.1 位置づけ

DXF は他の CAD との**交換用**として扱う。保存の正本は `.mcad`。取り込んだ図面はファイル名を持たない未保存の図面になり、
`Ctrl+S` で `.mcad` として保存する(元の DXF は上書きしない)。読み書きには Rust の `dxf` クレート 0.6.1 を使い、その
制約がそのまま仕様の制約になる(12.5 節)。

### 12.2 共通の対応

| 項目 | 書き出し | 取り込み |
|---|---|---|
| 版 | ヘッダ `$ACADVER` = R2007(文字列を UTF-8 で書くため。上げも下げもしない) | 版を問わない(クレートが読めるもの) |
| 単位 | `$INSUNITS` = 4(mm) | 読まない(常に 1 単位 = 1 mm) |
| カレントレイヤー | `$CLAYER` に名前を書く | その名前のレイヤーがあればカレントに |
| レイヤー | 既定レイヤーを LAYER テーブルの先頭に、残りを重ね順(奥から)に書く | テーブルの先頭を既定レイヤーに、出現順を重ね順にする |
| レイヤーのロック | 書けない | 常にロックなし |
| レイヤーの重ね順 | 出現順だけで表す(DXF に重ね順は無い) | 出現順。既定レイヤーの重ね順は 0 |
| 色 | ACI の 9 色(1 赤・2 黄・3 緑・4 水色・5 青・6 紫・7 白・8 濃灰 (65,65,65)・9 灰 (128,128,128))のうち RGB の二乗距離が最も近いもの | 9 色はその RGB、それ以外の ACI は (191,191,191) |
| 線種 | `CONTINUOUS`・`DASHED`・`DASHDOT`・`DIVIDE`(二点鎖線)を LTYPE に登録し、レイヤー・エンティティに書く | 名前を大文字小文字を区別せずに 4 種へ対応づける。知らない名前は実線。エンティティの `BYLAYER`・`BYBLOCK` は ByLayer |
| エンティティの線幅 | group 370(1/100 mm)に書く | 正の値は 0.05〜5.0 mm に丸めて取り込み、丸めた件数を数える。0 以下は ByLayer |
| レイヤーの線幅 | **書けない**(常に 0) | 正の値は取り込む。0 以下は既定 0.35 mm |
| 図面メタデータ・寸法スタイル | 書かない | 既定値(A4 横・1:1・様式B・枠非表示、既定の寸法スタイル)。新規図面の既定レイヤーは足さない |

- 取り込み時、LAYER テーブルに無いレイヤー名を参照するエンティティがあれば、その名前のレイヤーを作って割り当てる。

### 12.3 書き出し(`Ctrl+E`)

| mcad | DXF |
|---|---|
| 点・線分・円・円弧 | `POINT`・`LINE`・`CIRCLE`・`ARC`(角度は度) |
| ポリライン | `LWPOLYLINE`(閉じフラグ) |
| 構築線 | `XLINE`(基点と単位方向。数値は小数 12 桁) |
| 文字 | `TEXT`(位置・回転。高さは紙 mm × `k` のモデル長。揃えは左・ベースライン) |
| 寸法(5 種類) | **分解して** `LINE`(寸法線・補助線・引出線・下線・枠・接続線)・`SOLID`(塗りの矢先を三角形に分けたもの)・`ARC`(角度寸法の弧)・`TEXT`(文字)。線種は常に `CONTINUOUS`。文字の下の塗りは出さない。描くものが無い退化した寸法は何も書かない |
| 表・部品欄 | **分解して** 罫線を `LINE`、空でないセルを `TEXT`。中央・右揃えの列のセルは `TEXT` の水平揃え(group 72 = 1/2、基準点を group 10 と 11 に)で書く |
| 図面枠・表題欄 | 書かない |
| 拘束 | 書かない(拘束のある図面を書き出すと通知に `Constraints are not saved to DXF` を添える) |

- 通知: `Exported DXF file`。書けないエンティティがあれば `: {n} entity(ies) skipped (dimension not supported)` を添える。
- 他の CAD での表示: mcad が書いた日本語の `TEXT` は、受け取り側のフォント次第で文字化けする(LibreCAD で確認)。DXF に
  フォント本体は入らない。R2000 までしか読まない古い CAD で開けるかは確かめていない。

### 12.4 取り込み(`Ctrl+Shift+O`)

| DXF | mcad |
|---|---|
| `LINE`・`CIRCLE`・`ARC`・`LWPOLYLINE`・`POINT` | 図形 |
| `TEXT`(水平 Left かつ垂直 Baseline のもの) | 文字。高さの数値をそのまま紙 mm とみなす(尺度 1:1) |
| `TEXT`(それ以外の揃え) | 取り込まず、スキップ件数に数える |
| `XLINE` | 構築線(方向を正規化。z は捨てる)。方向が零・非有限ならスキップに数える。group 11 が無いと +X とみなす |
| `DIMENSION`: 整列・回転・直径・半径・3 点角度・座標 | 長さ寸法(整列 / 回転は group 50 の角度で `Rotated`)・直径・半径・角度・座標寸法 |
| `DIMENSION`: 2 直線角度・弧長 | **読めない。件数にも出ない**(クレートが返さない。LibreCAD の角度寸法はこれに当たる) |
| `ACAD_TABLE` | **読めない。件数にも出ない** |
| `RAY`・`SOLID`・`SPLINE`・`ELLIPSE`・`INSERT` など | スキップ件数に数える |

**寸法の取り込み**

- 次の寸法は値や位置が変わってしまうので取り込まず、寸法のスキップ件数に数える: 水平方向角(group 51)が 0 でない
  回転寸法、押し出し方向が +Z でない、計測点が
  退化している、実測値(group 42)が定義点から計算し直した値と食い違う(測定倍率 DIMLFAC など。group 42 が省略されて
  いれば検査しない。角度寸法は検査しない)、mcad の寸法として不正(半径 0 など)。
- 取り込むが属性を捨てるもの(件数に数える): 解釈できない文字テンプレート、補助線の傾き(group 52)、文字の回転
  (group 53)。文字テンプレートの `<>` の前後は接頭辞・接尾辞として取り込む。
- DIMSTYLE は読まない(見た目は mcad の寸法スタイルで描く)。寸法の見た目のブロック(`*D1` 等)は読まないので、線が
  二重に入ることはない。関連付けは無く、すべて静的な寸法として取り込む。

**ほかの規則**

- 壊れたエンティティ(非有限・負の半径・空文字列など)は、ファイル全体を失敗させずにスキップ件数へ数える。ファイル
  自体が読めないときは `DXF import failed: {理由}`。
- 通知: `Imported DXF file; layer locks are not restored from DXF`。件数があれば `Imported DXF: {件数の説明}; layer locks are
  not restored from DXF` で、説明は `{n} entity(ies) skipped (unsupported type)`・`{n} dimension(s) skipped (cannot be
  represented without changing the measured value or position)`・`{n} line width(s) clamped to the 0.05..=5.0mm range`・
  `{n} dimension(s) imported without unsupported details` を `, ` でつなぐ。
- 取り込みで捨てる文字の属性: 書体名・文字の幅の比など(mcad の文字は 1 書体だけ)。

### 12.5 往復の性質

| 経路 | 性質 |
|---|---|
| 図形・構築線・左揃えの文字 | 往復する(色は 9 色に近似、レイヤーのロック・線幅・既定レイヤーの重ね順は失う) |
| 文字の高さ | 尺度 1:1 以外では「紙 mm」の値は往復しないが、モデル空間の大きさは保たれる(1:2 で紙 3.5 mm → DXF 7.0 → 取り込み後は 1:1 の 紙 7.0 mm) |
| 寸法 | **非対称**: 書き出すと線・文字に分解され、読み戻しても寸法には戻らない(`SOLID` はスキップに数える)。一方、他の CAD が書いた `DIMENSION` は寸法として読める |
| 表・部品欄 | **非対称**: 罫線と文字に分解され、表には戻らない(罫線の太さの区別も失う)。中央・右揃えの列のセル文字はスキップに数える |
| 図面枠・表題欄・図面メタデータ | 書かない。読み戻した図面の図面メタデータは既定値(A4 横・1:1・様式B・枠は非表示。12.2 節)になり、元の用紙・尺度・表題欄は戻らない |
| 拘束・寸法の文字の下の塗り | 書かない |

## 13. 設定(`config.json`)

### 13.1 場所と書き方

- OS の標準の設定ディレクトリの `mcad/config.json`(Linux は `~/.config/mcad/config.json`)。図面の内容は書かない。
- 設定を変えるたびに書く(一時ファイル `config.json.tmp` に字下げ付きの JSON を書いてから置き換える)。書けなければ
  `Settings save failed: {理由}` を出す。
- 起動時に読む。ファイルが無ければ既定値。読めない・壊れているときは既定値で起動し、`Settings load failed (using
  defaults): {理由}` を出す。設定ディレクトリが無ければ `Settings directory unavailable; settings will not be saved`。
  どの場合も起動は止めない。
- 知らないキーは無視し、無いキーは既定値で補う(版をまたいで読める)。直交と極トラッキングが両方 ON のファイルは、
  極トラッキングを OFF にして読む。
- `config.json` は互換性の約束(11.5 節)の対象外。

### 13.2 キーと既定値

| キー | 型・値 | 既定 | 内容 |
|---|---|---|---|
| `snap_enabled` | 真偽 | `true` | スナップ(`F3`) |
| `ortho_enabled` | 真偽 | `false` | 直交モード(`F8`) |
| `polar_enabled` | 真偽 | `false` | 極トラッキング(`F10`) |
| `polar_step` | `"Fifteen"` / `"Thirty"` / `"FortyFive"` / `"Ninety"` | `"Fifteen"` | 極トラッキングの刻み角 |
| `paper_display_enabled` | 真偽 | `false` | 紙基準表示(`F9`) |
| `grid_mode` | `"Rectangular"` / `"Isometric"` | `"Rectangular"` | グリッド(`F5`) |
| `snap_kinds` | `{"endpoint", "intersection", "midpoint", "center", "quadrant", "perpendicular", "tangent", "virtual_intersection", "nearest", "grid"}` の真偽 | `nearest` だけ `false`、他は `true` | スナップの種類ごとの ON/OFF(キーごとに補う) |
| `constraint_symbols_visible` | 真偽 | `true` | 拘束記号の表示 |
| `plot_color_mode` | `"Monochrome"` / `"Blueprint"` / `"Color"` | `"Monochrome"` | SVG/PDF の出力色 |
| `default_paper` | `"A0"`〜`"A4"` | `"A4"` | 新規図面の用紙 |
| `default_orientation` | `"Landscape"` / `"Portrait"` | `"Landscape"` | 新規図面の向き |
| `default_scale` | `{"num", "den"}` | `{"num": 1, "den": 1}` | 新規図面の尺度 |
| `default_title_block` | `"A"` / `"B"` / `"C"` | `"B"` | 新規図面の表題欄の様式(ユーザー定義は既定にならない) |
| `recent_files` | パスの配列 | `[]` | 最近使った `.mcad`(新しい順、5 件まで。開く・保存のたびに先頭へ) |

- 新規図面の用紙・向き・尺度・様式の既定は、右パネル「図面」で図面のそれらを変えるたびに書き換わる(3.4 節)。新規図面の
  図面枠は常に非表示、「部品欄を使う」は常に ON で始まる。
- 寸法の末尾ゼロを省くかどうかは設定ではなく図面の寸法スタイル(`.mcad`)に保存する(6.7 節)。

## 14. 既知の制約・未対応

v1.0.0 時点で持たない機能と、分かっている制限。今後の候補とその検討は `DESIGN.md` が持つ。

### 14.1 持たない機能

| 分野 | 持たないもの |
|---|---|
| 図形 | 楕円・スプライン・ハッチング・中心線の専用機能・切断線・3D(Z 軸・ソリッド) |
| 編集 | 配列複製・尺度変更・ストレッチ・長さ変更、グループ化・ブロック(DXF の `INSERT` 相当)、選択フィルタ、窓/交差の矩形選択の区別 |
| スナップ | 延長線上の点・平行のスナップ |
| 文字 | 揃え(中央・右、縦の揃え)、複数行、書体の選択 |
| 寸法 | 弧長寸法、駆動寸法、寸法と図形の関連付け、半径・直径寸法の記号を消すこと、寸法線を基準線へ揃える機能、矢先のグリップ、フィレットと同時の寸法記入、Ⓔ 等の修飾子、はめあい記号の偏差値への展開 |
| 製図記号 | 幾何公差の記入枠・データム、表面性状、溶接記号、風船・引出線(エンティティとして) |
| 表・部品欄 | 図形からの自動集計、セルの結合、表の回転 |
| 拘束 | ポリライン・点・構築線への拘束、点を線・円の上に乗せる拘束、中点・対称の拘束、接点を線分・円弧の範囲内に保つ接線、重複の検出・警告、拘束の自動推定、複製・2 断片のトリム・分割での拘束の引き継ぎ、フィレット・面取りでの拘束の自動付与 |
| 図面 | 紙空間・複数のレイアウト、延長サイズの用紙、ユーザー定義の表題欄様式を作る・編集する UI、レイヤーの改名、エンティティの色の個別指定 |
| UI | メニューバー・リボン、複数図面の同時オープン(タブ)、英語・日本語以外の言語、UI 全体の日本語化(上部パネル等は英語) |
| ファイル | DXF の `RAY`・`ACAD_TABLE`・2 直線角度寸法・弧長寸法・揃えのある `TEXT` の取り込み、拘束・図面メタデータの DXF への保存、レイヤーのロック・線幅・重ね順の DXF 往復 |

### 14.2 分かっている制限

- **選択中の寸法**: 文字を自分の寸法線の上へ置いた寸法を選ぶと、強調色の線が文字の上に見える(選択の強調には塗りを
  入れないため。6.8 節)。
- **文字の下の塗り**: 重ね順が上のレイヤーの図形と、同じレイヤーで後から描いた図形は消さない。
- **画面の英字**: 画面の英字は GUI の既定フォントで描くので、寸法の文字の幅の見積もり(同梱フォントの実測)と少しずれる。
  SVG/PDF は正確。
- **文字エンティティの外形**: 文字数からの近似なので、実際の字形より狭い・広いことがある(選択の当たりに影響)。
- **紙基準表示 OFF の画面**: 接続線(6.8 節)の有無がズームで変わることがある。
- **線種の画面表示**: ダッシュの位相が画面の切り取り区間ごとに始まり直す(出力は正確)。
- **拘束の求解**: つながった拘束が大きい図面では、確定やプレビューが演算量の予算で拒否されることがある(8.6 節)。
- **性能**: 空間索引を持たず全件を走査する。20,000 エンティティの図面で、ピック・矩形選択・描画の絞り込みは 1 回あたり
  3 ms 台(開発環境での実測)。SVG/PDF 出力・保存・読込は全件を処理する。
- **ファイルダイアログ**: OS のネイティブダイアログを同期して開く(開いている間アプリの描画は止まる)。
- **ポリラインの自動で閉じる**: 始点への吸着はスナップによるので、スナップ OFF では始点クリックで閉じない。
- **DXF**: 12 章のとおり。特に、mcad が書いた日本語の `TEXT` は他の CAD で文字化けしうる。
