# 参考図面・図枠の入手先調査(2026-08-11)

`製図規定.md` の裏取りと、mcad の図面枠・表題欄(M8 タスク38 実装済み)の妥当性検証に使える
外部資料の調査記録。**調査のみで、mcad の実装へは何も取り込んでいない**(参照用の SVG は
[`参考図枠/`](./参考図枠/) へ同梱した。ビルドからは参照していない)。

## 結論(先に要点)

- **FreeCAD の TechDraw テンプレートが最有力**。ISO 5457 準拠の図枠と ISO 7200 準拠の表題欄が
  **SVG**で揃っており、ライセンスは **CC0 1.0(パブリックドメイン)**。SVG なので mcad の
  SVG 出力(タスク39)と直接見比べられる。
- **特定企業(例: 三菱重工)の実物の図枠は取得しない方針で確定。** 企業の表題欄は社名・ロゴ・
  図番体系がそのまま入っており、ネット上にあるものも社外秘の流出や第三者の再配布であることが
  多い。mcad へ取り込めば商標・なりすましの問題になる。**ISO 7200 の欄構成は各社の表題欄の
  共通の下敷きなので、実務的な設計意図(社名欄に4行分の領域が確保されている等)はこれで足りる。**
- 規格票(JIS Z 8311 / ISO 5457 / ISO 7200)の**条文そのものをリポジトリへ転記しない**。
  CC0 のテンプレートから読み取れる寸法・欄構成を根拠として引く。

## 入手先

### FreeCAD TechDraw テンプレート(CC0 1.0)

`github.com/FreeCAD/FreeCAD` の `src/Mod/TechDraw/Templates/`。

| 場所 | 中身 |
|---|---|
| `ISO/` | A0〜A3 横 + A4 横/縦の ISO 5457 図枠。各サイズに `advanced` / `minimal` / `notitleblock` / `blank` |
| `ISO/titleblocks/` | ISO 7200 表題欄 5 段階(`1_minimal` / `2` / `3_advanced` / `4` / `5_maximal`) |
| `ISO/localized/` | 各国語版(de / fr / it / es-AR / cs / ca / ru / zh-CN)。**日本語版は無い** |
| `ASME/` | 米国系テンプレート一式 |

ライセンスは各 SVG 内の RDF に `creativecommons.org/publicdomain/zero/1.0/` として記載。

取得例:

```
https://raw.githubusercontent.com/FreeCAD/FreeCAD/main/src/Mod/TechDraw/Templates/ISO/A4_Landscape_ISO5457_minimal.svg
https://raw.githubusercontent.com/FreeCAD/FreeCAD/main/src/Mod/TechDraw/Templates/ISO/titleblocks/ISO7200_titleblock_3_advanced.svg
```

### その他

- **LibreCAD / QCAD** — 同様に図枠テンプレートを同梱
- **公開特許公報(J-PlatPat)** — 公開情報だが、特許図面は寸法を入れない様式なので機械製図の参考としては限定的
- **NASA Technical Reports Server** — 米政府著作物でパブリックドメイン。実物の技術図面が大量にある
- **JIS Z 8311 / ISO 5457**(図面の大きさと様式)、**ISO 7200**(表題欄の記載項目) — JIS は
  日本産業標準調査会(JISC)のサイトで**閲覧のみ**可能(ダウンロード不可)

## 実測値: ISO 5457(A4 横)vs mcad 現状

FreeCAD `A4_Landscape_ISO5457_minimal.svg` の `<rect>` 座標から実測。

| 項目 | ISO 5457 | mcad 現状 |
|---|---|---|
| 輪郭の余白 | **左 20mm(とじしろ)**、右・上・下 10mm | 全周 10mm(`FRAME_MARGIN_MM`) |
| 輪郭線の太さ | 0.7mm | 0.5mm(`FRAME_BORDER_WIDTH_MM`) |
| 区域区分の外枠 | 用紙端から 5mm(277 × 200) | なし |
| 中心マーク | 4 辺の中央に 10mm の短線 | なし |
| 表題欄 | **180 × 36**、右下・輪郭の内側に接する | 様式A 170×30 / B 120×25 / C 170×40 |

対応する SVG の記述:

```xml
<rect id="drawing_space_frame"    x="20" y="10"  width="267" height="190" stroke-width="0.7"/>
<rect id="grid_reference_border"  x="15" y="5"   width="277" height="200"/>
<rect id="title_block_frame"      x="107" y="164" width="180" height="36"  stroke-width="0.7"/>
```

表題欄が右下・輪郭の内側に接する点は mcad と同じ(タスク38 の実装と一致)。

## 実測値: ISO 7200 の欄 vs mcad の 8 欄

mcad の `TitleBlockField`(8種): 図面名 / 図番 / 作成者 / 日付 / 尺度 / 投影法 / 用紙サイズ / 改訂

### mcad にあって ISO 7200 に無い

- **投影法(projection)** — ISO では投影法の記号を表題欄の外に置くことが多い
- **用紙サイズ(paper size)**

どちらも JIS 系の慣行なので、日本の図面としては残す方が自然。

### ISO 7200 にあって mcad に無い(実務で頻出のもの)

`ISO7200_titleblock_1_minimal.svg` の `freecad:editable` 属性より。

| 欄 | 備考 |
|---|---|
| **legal owner** | 所有者・社名。**4 行分**の領域が確保されている |
| **part material** | 材質 |
| **general tolerances** | 一般公差。記入例は `ISO 2768-m` |
| **approval person** | 承認者。mcad は作成者のみ |
| **sheet number** | シート番号(X / Y) |
| **document type** | 部品図 / 組立図 |
| **language code** | 言語コード |

上位版(`3_advanced` / `5_maximal`)ではさらに **document status**(状態)・
**responsible department**(部署)・**supplementary title**(副題 1・2)・
**technical reference**・**key words**・**page number** が加わる。

`3_advanced` の欄割り(180 × 48mm、`<rect>` 座標より):

```
title(0,0,80×24)  creator(80,0,60×12)          legal owner(140,0,40×24)
                  approval_person(80,12,60×12)
document_type     identification_number         responsible_department
(0,24,80×12)      (80,24,60×12)                 (140,24,40×12)
document_status   language(80,36,20×12)  date(100,36,40×12)
(0,36,80×12)      revision(140,36,20×12) sheet_number(160,36,20×12)
```

## mcad への反映候補(未着手・未決定)

1. **材質・一般公差・承認者・所有者の欄を足す** — 実際に図面を書くと必ず要る。
   様式C には予備欄(`None` セル)が 2 つあるのでそこへ割り当てるか、
   **ISO 7200 準拠の様式D を新設**する。
2. **表題欄の幅を 180mm まで許容する** — mcad の最大は現状 170mm(様式A・C)。
3. **とじしろ(左 20mm)** — 現状は全周 10mm 固定。綴じる運用を想定するなら左だけ広げる。
   `FRAME_MARGIN_MM` を 4 辺個別の値へ広げる変更になる。
4. **区域区分(grid reference)と中心マーク** — 大判図面で位置を指し示すために使う。
   A4 では実用性が低いので優先度は低い。

いずれも M8 のスコープ外。着手するなら M8 完了後(v0.8.x の番号外または M9)。
エンティティのレイヤー変更コマンドと同じ扱い。
